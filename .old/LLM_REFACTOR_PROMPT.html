Refactor for functional + polished VS Code UI

You are an expert full-stack engineer and product-minded UI designer. Build a more functional, polished VS Code–like Python course shell for students transitioning from C/Java. Tags and metadata must never break in lectures, subcategories, pages, or exercises.

02

Hard constraints

XML structure edits allowed
via Python scripts
You may change source XML under materialy/**/*.xml and especially priklady/**/*.xml for UI structure (wrap úkols, stable ids/attrs, split sections, meta hooks for tags/diff/relevance).

Do not hand-edit dozens of XML files ad-hoc. Prefer reproducible Python transform scripts (tools/ or scratch/): parse → transform → write → python build_html.py. Prefer idempotent scripts. Preserve educational prose; do not rewrite content unless structure requires it.
Stable slide / task IDs
Keep id="id{position()}" on .slide-section (and stable ids on exercise tasks if introduced). Keys: slug#idN e.g. pip#id3. Never reintroduce generate-id() for anchors. If a transform reorders nodes, update or regenerate classification keys in the same pipeline.
No aggressive page caching
No long-lived SPA page cache. Prefer fetch(..., { cache: 'no-store' }), cache-bust assets, start_course.py no-cache headers. Users must not need Incognito after rebuilds.
Tree only in left sidebar
3-layer tree (weeks → lectures/exercises → pages) lives in EXPLORER only. Do not dump a second full tree into the main catalog as primary nav.
Category click behavior
Week/lecture click → main pane gets rich index card + page cards (titles, badges, optional short preview). No full subpage body dumps. Auto-scroll if many cards.
Prefer build-time page data
data/lecture-pages.json is first-class: { path → [{ id, title, content }] }. Do not re-scrape full HTML client-side for structure.
Dual cjs/ copies
Root cjs/ and vyuka_downloaded/cjs/ often mirror. Update both or introduce single source of truth + sync.
Language & extras
UI chrome Czech/bilingual carefully; desc/compare stay Czech. No full Pyodide Python console. Stay educational.

Metadata model

Lecture-level courseData
  • title, path
  • diff: basics | resyntax | newconcept | pythonic | paradigm
  • relevance: ~1–10
  • tags: Core · WOW · Legendary · Tricky · Skip
  • desc, compare (Czech)
Slide / exercise task
  • DOM id idN on each section

  • Exercises under priklady/ must keep badges in subcats
06

Known bug classes — fix first, never reintroduce

1
Tag / classification desync

Random ids (generate-id()) or slug mismatch → wrong/missing chips.

2
Tags missing in tree / subcategories

Explorer + category cards must match lecture badges; filters must apply coherently.

3
Exercise tag bugs

examples.screen.* path differs; do not strip data-* or section ids.

4
Stale UI after rebuild

Map cache / HTTP cache looks like “tags disappeared”.

5
const/let not on window

Use window.courseData, lecturePagesData, SLIDE_CLASS.

6
Empty layer 3 / wrong paths

Keys in lecture-pages.json must equal courseData[].path.

7
Typography layout jump

Not everything bold; weight changes must not shift layout.

07

Target product

Shell (VS Code)

Title bar · activity bar · EXPLORER (resizable) · tab bar · editor · status bar. Theme tokens, theme-aware scrollbars. Fonts: IBM Plex / JetBrains Mono (400 body, 500/600 sparingly).

Main / editor

Rich index card + page cards (not full bodies). Open page via inject or full lecture + scroll to #idN. Outline/scroll sync if feasible. Code blocks feel like VS Code.

3-layer explorer (left only)
▾ Week 0 — Příprava prostředí
▾ Správce balíčků pip & wheel Corenewconcept
id1 · Úvod
id3 · requirements.txt
▸ Modul venv
▸ Week 1 — …

Click page → open in editor. Click lecture/week → main shows index + page cards only.

Tags & filters everywhere

Global filters: tag, difficulty, relevance, free-text (search_index.json). Filtered items hide/dim in tree and main. Slide chips on correct section.

High-value extras polish over feature spam
  1. Tabs + visited state + Ctrl+P / Ctrl+B
  2. Progress in localStorage
  3. Breadcrumbs Week › Lecture › Page
  4. Outline / mini-TOC scroll sync
  5. Unified course-manifest (optional)

Avoid: Pyodide console, HTML export prototypes, one-off scratch UI in production.

10

Quality & out of scope

Code quality
  • Prefer modules over 2k-line inline scripts
  • CSS variable-driven (tokens.css)
  • Nav + tags consolidation is in scope
  • After structure changes, rebuild immediately
Out of scope
  • Mass rewrite of educational prose
  • Hand-editing hundreds of XML files without a script
  • Auth / LMS / native mobile
  • Unreviewed auto-classification of all slides
  • Full in-browser Python interpreter
