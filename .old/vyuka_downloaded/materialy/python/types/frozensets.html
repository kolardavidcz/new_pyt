„Zmražené/zamrzlé“ množiny

by Jiří Znamenáček

1

Úvod

„Zmražené“ či „zamrzlé“ množiny jsou neproměnnou (immutable) variantou množin. Dá se o nich tedy z větší části říci úplně to samé, co o množinách:

Zmražená množina je neuspořádaná kolekce jedinečných a neměnných (immutable) hodnot.

Narozdíl od množin však tuto kolekci nemůžeme žádným způsobem měnit.

📝
Je mezi nimi tedy tak trochu podobná korespondence jako mezi seznamy a n-ticemi.
2

Zavedení – „frozenset()“

K vytvoření zmražené množiny slouží konstruktor frozenset(ITERABLE), který přebírá na vstupu iterovatelný objekt složený z prvků neproměnných (immutable) typů, ze kterých složí výslednou zmraženou množinu: 

>>> xs = [1, 2, 'ahoj', 3, 'b', 'ahoj', 3, ]
>>> fs = frozenset(xs)

>>> fs
frozenset({1, 2, 3, 'ahoj', 'b'})

>>> type(xs)
<class 'frozenset'>
📝
Duplikáty ze vstupního objektu byly automaticky odstraněny, protože vyrábíme množinu.

Vstupem do konstruktoru může být samozřejmě i „obyčejná“ množina – dá se procházet po jejích prvcích plus jsou prvky již automaticky neproměnné a každý je tam navíc již pouze jednou: 

>>> s = { 1, 2, 'ahoj', 3, 'b', }
>>> frozenset(s)
frozenset({'ahoj', 1, 2, 3, 'b'})
3

Prázná „zmražená“ množina

Prázdnou zmraženou množinu vytvoříme pomocí funkce frozenset(): 

>>> fs = frozenset()
>>> fs
frozenset()

>>> type(fs)
<class 'frozenset'>

Žádná odpovídající přímá notace neexistuje, takže se sice upíšeme, ale zase se vyhneme zmatení od množin.

4

Základní vlastnosti

Ačkoli zmražené množiny nepatří mezi sekvence, některé z vlastností mají – díky své struktuře „balíků na hodnoty“ – společné: 

>>> fs = frozenset( { 1, 2, 'ahoj', 3, 'b', } )

# dotaz na počet prvků
>>> len(fs)
5

# dotaz na výskyt prvku
>>> 'b' in fs
True
>>> 5 in fs
False

Podoba se vztahuje dokonce i na procházení prvků množiny smyčkou for-in, jen je příslušné procházení – podobně jako u slovníků – „náhodné“: 

>>> fs = frozenset( { 1, 2, 'ahoj', 3, 'b', } )

>>> for x in fs:
...     print(x)
...
ahoj
1
2
3
b
📝
Varianta s enumerate() funguje také, ale jelikož pořadí výpisu prvků je v podstatě „náhodné“, tak má poněkud omezenější použití, než u sekvenčních typů. Stejně tak samotný cyklus for-in najde využití spíše pro „množinové“ operace, kde nás zajímají vlastnosti či funkce prvků a nikoli jejich pořadí.
5

„Zmražené“ množiny jako neproměnný datový typ

Protože zmražené množiny jsou neproměnný (immutable) datový typ, veškeré množinové operace, které sloužily k přidávání a odebírání prvků, u nich nejsou pochopitelně podporovány. Konkrétně se tedy jedná o následující operace:

  • operace pro přidávání prvků – add(), update()
  • operace pro odebírání prvků – discard(), remove(), pop(), clear()

Ostatně podívejme se na výpis podporovaných atributů u zmražené množiny: 

>>> fs = frozenset()
>>> dir(fs)
['__and__', '__class__', '__contains__', '__delattr__', '__doc__', '__eq__',
 '__format__', '__ge__', '__getattribute__', '__gt__', '__hash__', '__init__',
 '__iter__', '__le__', '__len__', '__lt__', '__ne__', '__new__', '__or__',
 '__rand__', '__reduce__', '__reduce_ex__', '__repr__', '__ror__', '__rsub__',
 '__rxor__', '__setattr__', '__sizeof__', '__str__', '__sub__',
 '__subclasshook__', '__xor__', 'copy', 'difference', 'intersection',
 'isdisjoint', 'issubset', 'issuperset', 'symmetric_difference', 'union']
6

Množinové operace

Jinak jsou ovšem zmražené množiny stále ještě množinami, takže podporují všechny množinové operace (jak jsme ostatně viděli ve výpisu na předchozím slajdu), a to v obou jejich variantách – operátorově i množinově. Pro jednoduchost si je pouze shrňme a na použití odkažme k příkladům u množin:

Základní množinové operace:

  • průnik – &, intersection()
  • sjednocení – |, union()
  • rozdíl – -, difference()
  • symetrický rozdíl – ^, symmetric_difference()

Dotazy na množiny:

  • test (vlastní) podmnožiny – <= <, issubset()
  • test (vlastní) nadmnožiny – >= >, issuperset()
  • test výskytu prvku (pouze operátorově) – in, not in

Zjištění nulového průniku (nemá operátorovou variantu):

  • isdisjoint()
7

Kopie množiny

Jako jedna z mála datových struktur nabízí zmražená množina i vlastní metodu pro tvorbu kopie – copy(). Narozdíl od slovníku však prvky množiny mohou být pouze hešovatelné, tedy neproměnné (immutable) typy, takže při kopírování nenarazíme na problém s mělkou vs hlubokou kopií: 

>>> xs = frozenset( { 1, 2, 'ahoj', 3, 'b', } )
>>> xs
frozenset({'ahoj', 1, 2, 3, 'b'})

>>> ys = xs.copy()
>>> ys
frozenset({'ahoj', 1, 2, 3, 'b'})

>>> xs = frozenset()   # nahrazení původní zmražené množiny prázdnou
>>> xs
frozenset()
>>> ys                 # zkopírovaná množina se zachovává
frozenset({'ahoj', 1, 2, 3, 'b'})
