Objekt bajtkódu

by Jiří Znamenáček

1

Úvod

Objekt zkompilovaného kódu má k dispozici mnoho vlastností: 

>>> co = compile('xs = [1]', '<string>', 'exec')

>>> co
<code object <module> at 0x00ABA980, file "<string>", line 1>

>>> dir(co)
['__class__', '__delattr__', '__doc__', '__eq__', '__format__', '__ge__',
 '__getattribute__', '__gt__', '__hash__', '__init__', '__le__', '__lt__',
 '__ne__', '__new__', '__reduce__', '__reduce_ex__', '__repr__', '__setattr__',
 '__sizeof__', '__str__', '__subclasshook__', 'co_argcount', 'co_cellvars',
 'co_code', 'co_consts', 'co_filename', 'co_firstlineno', 'co_flags',
 'co_freevars', 'co_kwonlyargcount', 'co_lnotab', 'co_name', 'co_names',
 'co_nlocals', 'co_stacksize', 'co_varnames']

V dalším si ty nejdůležitější (na uvedeném příkladu xs = [1]) postupně probereme.

📝
Popis a rozdělení podle Python’s Innards: Code Objects a podle dokumentace k modulu inspect.
2

Funkce „compile“

Na bajtkód příslušející danému zdrojovému kódu se můžete asi nejsnáze podívat tak, že ho jako řetězec „předhodíte“ funkci compile(): 

>>> co = compile('xs = [1]', '<string>', 'exec')
>>> co.co_code
    b'd\x00\x00g\x01\x00Z\x00\x00d\x01\x00S'

Ta má více parametrů, ale povinné jsou pouze první tři z nich (tedy všechny zde použité):

  1. source – zdrojový kód jako řetězec nebo AST-objekt
  2. filename – soubor obsahující načtený zdrojový kód (pokud jsme kód nenačetli ze souboru, typicky se zde uvádí právě <string>, ale projdou i jiné snadno zařaditelné hodnoty)
  3. mode – způsob kompilace zdrojového kódu (exec pro posloupnost příkazů, eval pro jeden konkrétní výraz, single pro jeden konkrétní interaktivní příkaz)
📝
Tedy je-li prvním paramatrem (i víceřádkový) zdrojový kód Python'u, je obsahem dalších dvou typicky právě <string> (aneb „kód není načítán ze souboru“) a exec (aneb „vykonej kód pomocí funkce exec()“).
📝
V dřívejších verzích Python'u musel řetězec na vstupu funkce compile() končit na novou řádku. Avšak od verze 3.2 při použití metody exec() to již není potřeba. Zároveň pro ostatní metody je možno použít libovolné konce řádků (tedy jak z Windows, tak z Unixu).
3

Identifikace objektu

  • jméno tohoto code-objektu (pro zkompilované funkcí compile() je zde vždy <module>): 
                    >>> co.co_name
                    '<module>'
  • jméno souboru, ze kterého byl kód zkompilován: 
                    >>> co.co_filename
                    '<string>'
4

Jména proměnných

  • n-tice jmen argumentů a lokálních proměnných: 
                    >>> co.co_varnames
                    ()
  • n-tice jmen lokálních proměnných, která jsou uložena v buňkách (tedy proměnných, které jsou referencované z více míst s různou viditelností): 
                    >>> co.co_cellvars
                    ()
  • n-tice jmen volných proměnných: 
                    >>> co.co_freevars
                    ()
  • n-tice jmen (lokálních proměnných), která nezapadají do žádné výše uvedené škatulky: 
                    >>> co.co_names
                    ('xs',)
5

Čítače a ukazatele

  • počet očekávaných argumentů (pozičních i pojmenovaných, ale bez * a **): 
                    >>> co.co_argcount
                    0
  • počet očekávaných pojmenovaných argumentů: 
                    >>> co.co_kwonlyargcount
                    0
  • počet využitých lokálních proměnných (včetně argumentů): 
                    >>> co.co_nlocals
                    0
  • relativní pozice prvního řádku kódu vůči modulu, v němž je definován: 
                    >>> co.co_firstlineno
                    1
  • potřebná velikost zásobníku (kompilátor ji zjistí analýzou kódu): 
                    >>> co.co_stacksize
                    1
6

Ostatní vlastnosti

  • binární řetězec operačních instrukcí bajtkódu a jejich argumentů (tyto argumenty jsou většinou indexy do ostatních polí objektu co): 
                    >>> co.co_code
                    b'd\x00\x00g\x01\x00Z\x00\x00d\x01\x00S'
  • n-tice všech konstantních hodnot (literals) použitých bajtkódem: 
                    >>> co.co_consts
                    (1, None)
  • binární řetězec sloužící k uložení mapování relativních pozic (offsetů) bajtkódu na čísla řádek: 
                    >>> co.co_lnotab
                    b''
    📝
    Jméno pochází z line number table.
  • číslo složené z příznaků indikujících způsob vytvoření objektu: 
                    >>> co.co_flags
                    64
    📝
    64 odpovídá 0x0040, tj. příznaku CO_NOFREE
    📝
    Složení příslušných osmi bitů je: 1=optimized | 2=newlocals | 4=*arg | 8=**arg
7

Speciální vlastnosti

Několik dalších položek (fields) definovaných na struktuře (struct) PyCodeObject není dostupných přímo v Python'u:

  • co_zombieframe – interní použití pro optimalizaci (recyklace rámců; viz frameobject.c)
  • co_cell2arg – provázání buňkových proměnných, které jsou argumenty
  • co_weakreflist – pro podporu slabých referencí na bajtkód-objekty
8

„dis.show_code()“

Některé z těchto vlastností vám s výhodou okomentovaně vypíše i metoda show_code() objektu dis: 

>>> dis.show_code('xs = [1]')

Filename:          <code_info>
Argument count:    0
Kw-only arguments: 0
Number of locals:  0
Stack size:        1
Flags:             NOFREE
Constants:
   0: 1
   1: None
Names:
   0: xs
