Modul „argparse“

by Jiří Znamenáček

1

Úvod

Modul argparse je poslední inkarnací nadstavbových modulů pro zpracování argumentů příkazové řádky skriptu.

Názory na jeho uspořádání a použití se různí, ale za sebe mohu říct, že pro člověka, který potřebuje příležitostně zpracovat pár argumentů na příkazové řádce, je na použití zdaleka nejprůhlednější a nejpříjemnější. Proto jsem mu věnoval samostatnou kapitolu, ve které se pokusím to důležité z oficiální dokumentace převyprávět na menší ploše.

2

Příklad

Ukažme si nejdříve chování kódu vybaveného modulem argparse při různých voláních skriptu z příkazové řádky. Daný skript pouze (přehledně) vypisuje, jaké argumenty na příkazové řádce obdržel:

Nevíme, jak program vůbec zavolat, tak to zkusíme bez parametrů:

💻 Command
python3 argparse.mod.py
▶ Output

Aha, takže přepínače nejsou povinné, ale jméno souboru ano. Tak ho zkusíme přidat (test.html):

💻 Command
python3 argparse.mod.py test.html
▶ Output

Vida, přepínače mají nějaké výchozí hodnoty. Nebyla by k nim nějaká nápověda?

💻 Command
python3 argparse.mod.py --help
▶ Output
📝
A jak je dobrým zvykem, téhož výsledku dosáhneme zavoláním: python3 argparse.mod.py -h

Tak to zkusme všechno najednou:

💻 Command
python3 argparse.mod.py -x -c stylopis.css test.html
▶ Output
📝
Přepínačem -c jsme změnili stylopisový soubor (klíč cssfile) z výchozího style.css na stylopis.css a přepínačem -x jsme změnili výchozí hodnotu klíče xhtml_flag z False na True. test.html je jméno souboru (určeného ke zpracování).
📝
V „dlouhém“ provedení by volání vypadalo: python3 argparse.mod.py --xhtml --cssfile=stylopis.css test.html (znak = tam sice není povinný, ale lépe se to s ním čte)

Aby se neřeklo, tak ještě obligátní dotaz na verzi programu :)

💻 Command
python3 argparse.mod.py --version
▶ Output
3

Příklad – zdrojový kód

4

Několik poznámek

  • Mnoho atributů nastavení je nepovinných, potřebné hodnoty se v běžných případech doplní celkem logicky.
  • Mezi přepínači a pozičními argumenty není z hlediska zavedení prakticky žádný rozdíl.
    📝
    Díky čemuž je uvedení pozičních hlídáno automaticky a nemusíte je pracně ručně ověřovat a vyhazovat výjimku, když se nedopočítáte potřebného počtu.
  • Návratový objekt je pouze jeden, jednotlivé argumenty (a to i poziční) jsou v něm přístupné pod svými jmény.
    📝
    Také z něj jde udělat slovník pomocí funkce vars(). Jinak sám o sobě je to v podstatě pouze objekt s pojmenovanými atributy.
5

Vytvoření parseru

Nový objekt pro zpracování argumentů příkazové řádky založíme pomocí třídy ArgumentParser. Ta má hafo nepovinných parametrů, z nichž nejužitečnější jsou asi následující dva: 

        parser = ArgumentParser(description="", epilog="")
  • description – text v nápovědě mezi vzorem příkazové řádky a popisem jednotlivých argumentů
  • epilog – text úplně na konci nápovědy
6

Přidávání argumentů I

O přidávání argumentů do parseru se stará metoda add_argument(). Ta má jediný povinný parametr (nebo skupinu parametrů) – řetězec (řetězce) zadávající jména argumentů. Přitom nepovinné parametry (tzv. přepínače) se od povinných (pozičních) liší přítomností znaménka „-“ (v základním nastavení) před svým jménem: 

        parser.add_argument('-x', '--xhtml')
        parser.add_argument('file')

📝
Znak(y) použité pro identifikaci přepínačů je možno předepsat při zavádění parseru: 
            parser = argparse.ArgumentParser(prefix_chars='-+/')
7

Přidávání argumentů II

Zadané argumenty z příkazové řádky skončí ve výstupním objektu Namespace přímo pod svými „dlouhými“ jmény:

  • Nezadaný přepínač získá výchozí hodnotu None:
    💻 Command
    test.py baf
    ▶ Output
                        Namespace(file='baf', xhtml=None)
  • Přepínače se mohou vyskytovat na libovolném místě zadání a se svojí hodnotou mohou – ale také nemusí (v případě „krátké“ varianty) – být spojeny pomocí znaku = nebo mezery:
    💻 Command
    test.py baf -x haf
    ▶ Output
                        Namespace(file='baf', xhtml='haf')
    💻 Command
    test.py baf -xhaf
    ▶ Output
                        Namespace(file='baf', xhtml='haf')
    💻 Command
    test.py -x=haf baf
    ▶ Output
                        Namespace(file='baf', xhtml='haf')
    📝
    Pro „dlouhou“ variantu jsou tedy ale možné pouze varianty --xhtml haf a --xhtml=haf.
    📝
    Naopak více přepínačů (z nichž nejvýše ten poslední očekává nějaký vstup) může být spojeno dohromady, tj. může být pravda například: test.py -x -y -z ⇔ test.py -xyz
8

Získání argumentů I

Za „vytažení“ argumentů z příkazové řádky je zodpovědná metoda parseru parse_args().

📝
Ve výchozím nastavení bere svůj vstup ze sys.argv, ale podle potřeby jí stačí přeposlat jako vstup seznam řetězců (tedy v principu stejný seznam jako vrátí sys.argv[1:]).

Ta se pokusí podle předpisů z metod add_argument() získat odpovídající hodnoty, kterými naplní návratový objekt Namespace, kde jsou přístupné pod klasickou tečkovou notací:

💻 Command
test.py -x soubor
📄 Program
            parser.add_argument('-x', '--xhtml', action='store_true')
            parser.add_argument('file')
            args = parser.parse_args()
            print(args)
            print('xhtml:', args.xhtml)
            print('file:', args.file)
▶ Output
            Namespace(file='soubor', xhtml=True)
            xhtml: True
            file: soubor
📝
Potřebujete-li místo toho přidat naparsované argumenty do jiného již existujícího objektu, stačí použít parametr namespace:
💻 Command
test.py -x soubor
📄 Program
                class MojeArgumenty:
                    pass
                ma = MojeArgumenty()
                
                parser.parse_args(namespace=ma)
                print(ma)
                print('xhtml:', ma.xhtml)
                print('file:', ma.file)
▶ Output
                <__main__.MojeArgumenty object at 0x00C2B110>
                xhtml: True
                file: soubor
9

Získání argumentů II

Zároveň se metoda parse_args() pokusí pohlídat většinu chyb, ke kterým může dojít, a v případě výskytu jakékoli z nich běh programu zastaví:

💻 Command
test.py
📄 Program
            parser.add_argument('-x', '--xhtml', action='store_true')
            parser.add_argument('file')
            args = parser.parse_args()
▶ Output
            usage: test.py [-h] [-x] file
            test.py: error: too few arguments
10

Získání argumentů III

Poziční argument, který začíná na označovač přepínače (ve výchozím nastavení tedy znak -), může pochopitelně v některých případech při načítání způsobit pěkné trable. Chcete-li zdůraznit, že od jistého místa v zadání dále se vyskytují již pouze poziční argumenty, použijte pseudorozdělovač --:

💻 Command
test.py -x -- soubor
📄 Program
            parser.add_argument('-x', '--xhtml', action='store_true')
            parser.add_argument('file')
            args = parser.parse_args()
            print(args)
            print('xhtml:', args.xhtml)
            print('file:', args.file)
▶ Output
            Namespace(file='soubor', xhtml=True)
            xhtml: True
            file: soubor
11

Vlastnosti argumentů

Konkrétní chování argumentů předepisuje armáda nepovinných parametrů, které jsou však všechny užitečné a proto si je postupně probereme:

  • default – výchozí hodnota pro nezadaný argument
  • required – je daný argument vyžadován?
  • dest – alternativní název pro uložení argumentu
  • type – typ argumetu
  • choices – množina možných hodnot argumentu
  • action – operace k vykonání při zadání argumentu
  • nargs – násobnost argumentu
  • const – konstanta (vyžadována některými kombinacemi action a nargs)
  • help – nápověda pro argument
  • metavar – alternativní označení argumentu do nápovědy
12

Parametr „default“

Výchozí hodnotou pro nepovinné argumenty je None. Chceme-li jinou výchozí hodnotu, použijeme parametr default:

💻 Command
test.py
📄 Program
            parser.add_argument('-x', default="x.py")
            parser.add_argument('-y')
▶ Output
            Namespace(x='x.py', y=None)

Poznámka 1: Nepovinné argumenty jsou především všechny přepínače (není-li pomocí required řečeno jinak), ale patří mezi ně i poziční s možnou násobností 0 (tedy při nargs="?" a nargs="*").

Poznámka 2: Nebude-li nepovinný argument zadán, můžeme místo „probublání“ výchozí hodnoty též úplně zamezit jeho objevení ve výsledném objektu pomocí volby default=argparse.SUPPRESS.

13

Parametr „required“

Potřebujeme-li si přítomnost nějakého přepínače vynutit, použijeme atribut required: 

        parser.add_argument('-x', required=True)
        parser.add_argument('-y')
💻 Command
test.py
▶ Output
            usage: test.py [-h] -x X [-y Y]
            test.py: error: argument -x is required
💻 Command
test.py -x=haf
▶ Output
            Namespace(x='haf', y=None)
14

Parametr „dest“

Pokud z nejrůznějších důvodů potřebujeme uložit zadaný přepínač pod jiným názvem než je jeho „dlouhá“ hodnota z metody add_argument(), použijeme parametr dest:

💻 Command
test.py
📄 Program
            parser.add_argument('-x', '--xhtml', dest="metajazyk")
▶ Output
            Namespace(metajazyk=None)
15

Parametr „type“

Modul argparse umí pohlídat typ zadávaných parametrů a provést příslušnou automatickou konverzi z výchozího řetězce:

💻 Command
test.py -x=2 -y=2
📄 Program
            parser.add_argument('-x')
            parser.add_argument('-y', type=int)
▶ Output
            Namespace(x='2', y=2)
            x: <class 'str'>
            y: <class 'int'>

Jelikož typem může být odkaz na libovolný callable-objekt, tedy např. funkci nebo metodu, jsou možnosti zadání vskutku veliké – projde kupříkladu i zadání typu type=open.

16

Vyrobení vlastního typu

Vyrobení alternativního typu je směšně jednoduché – stačí např. předat odkaz na funkci, jejímž jediným vstupem bude příslušný řetězec z příkazové řádky. A s ním si pak už můžete dělat, co chcete.

📝
Funkce přitom musí vracet svůj vstupní argument (podrobený případné transformaci), nebo vyhodit výjimku argparse.ArgumentTypeError .

Kupříkladu zadání hexadecimálního čísla v intervalu 0x00 až 0xff by mohla hlídat například takováto funkce: 

        from argparse import ArgumentTypeError
        
        def rozsah(val):
            try:
                n = int(val, base=16)
                if 0 <= n <= 255:
                    return n
                else:
                    msg = 'Uvedené číslo nespadá do povoleného rozsahu!'
                    raise ArgumentTypeError(msg)
            except ValueError:
                msg = 'Zadaný vstup se nepodařilo převést na číslo!'
                raise ArgumentTypeError(msg)
         
         # zadání příslušného argumentu
         parser.add_argument('-r', '--rozsah', type=rozsah)
💻 Command
test.py -r ff
▶ Output
            Namespace(rozsah=255)
💻 Command
test.py -r 100
▶ Output
            usage: test.py [-h] [-r ROZSAH]
            test.py: error: argument -r/--rozsah: Uvedené číslo nespadá do povoleného rozsahu!
17

Parametr „choices“

Pokud má mít nějaký přepínač pouze jistou množinu povolených hodnot, přidejte parametr choices=VÝBĚR, kde VÝBĚRem může být jakýkoliv typ, který podporuje operátor in, zde například seznam: 

        parser.add_argument('-e', '--env',
                            dest='environment',
                            choices=['production', 'staging', 'testing',],
                            default='production',
                            help='Environment to run on')
💻 Command
test.py
▶ Output
            Namespace(environment='production')
💻 Command
test.py -e testing
▶ Output
            Namespace(environment='testing')
💻 Command
test.py -e run
▶ Output
            usage: test.py [-h] [-e {production,staging,testing}]
            test.py: error: argument -e/--env: invalid choice: 'run' (choose from 'production', 'staging', 'testing')

Stejně tak dobře můžete ale napsat klidně i toto: 

        parser.add_argument('-n', '--number',
                            type=int,
                            choices=range(1, 10),
                            help="Celočíselný multiplikátor v rozsahu 1-9")
18

Parametr „action“

Parametr action určuje, co bude provedeno s hodnotou příslušného argumentu na příkazové řádce. Má k dispozici následující hlavní standardní operace..

  • store – uloží zadanou hodnotu (ve výchozím nastavení jako řetězec) pod daným jménem; toto je výchozí chování metody add_argument()
  • store_const – je-li odpovídající přepínač přítomen, uloží hodnotu parametru const= na tomto argumentu
  • store_true & store_false – uloží boolovskou hodnotu True nebo False
  • append – přidá zadanou hodnotu do seznamu (využití u opakujících se argumentů)
  • append_const – je-li odpovídající přepínač přítomen, přidá do seznamu hodnotu parametru const= na tomto argumentu

..plus jednu specializovanou:

  • version – vypíše hodnotu parametru version= na tomto argumentu

Navíc si můžete připsat další vlastní operace rozšířením objektu argparse.Action, budete-li potřebovat.

19

action='store'

Uložení zadané hodnoty pod příslušným jménem je výchozí chování parseru argumentů:

💻 Command
test.py -x ahoj
📄 Program
            parser.add_argument('-x')
▶ Output
            Namespace(x='ahoj')
💻 Command
test.py -x ahoj
📄 Program
            parser.add_argument('-x', action='store')
▶ Output
            Namespace(x='ahoj')
📝
Nezapomeňte, že pokud neurčíte jiný typ, je hodnota uložena jako řetězec přímo převzaný z příkazové řádky.
20

action='store_const'

Pro přepínače je možné použít specifický způsob zadání hodnoty – je-li nastaveno action='store_const', signalizuje přítomnost přepínače na příkazové řádce, že pod dané jméno se má uložit hodnota odpovídajícího parametru const=: 

        parser.add_argument('-x', action='store_const', const='text')
💻 Command
test.py
▶ Output
            Namespace(x=None)
💻 Command
test.py -x
▶ Output
            Namespace(x='text')
📝
Ukládané hodnoty nejsou pochopitelně typem omezeny na řetězce, klidně to mohou být třeba odkazy na funkce.
21

action='store_true' & action='store_false'

Tyto dvě akce představují speciální variantu store_const, pouze pod příslušné jméno je uložena odpovídající pravdivostní hodnota: 

        parser.add_argument('-x', action='store_true')
        parser.add_argument('-y', action='store_false')
💻 Command
test.py
▶ Output
            Namespace(x=False, y=True)
💻 Command
test.py -x -y
▶ Output
            Namespace(x=True, y=False)
22

action='append'

Parametr action='append' je velmi výhodný například v případě, kdy se příkazová řádka skládá z více nezávislých kusů a některé z přepínačů se navzájem nepřebíjí (metodou „poslední vítězí“), ale naopak skládají dohromady: 

        parser.add_argument('-x', action='append')
💻 Command
test.py -x 1
▶ Output
            Namespace(x=['1'])
💻 Command
test.py -x 1 -x=2
▶ Output
            Namespace(x=['1', '2'])
23

action='append_const'

Parametr action='append_const' se chová velmi podobně jako parametr append, jen místo zadané hodnoty se ukládá hodnota z parametru const=. Obzvláště šikovné, pokud má více argumentů stejný cíl: 

        parser.add_argument('--str', dest='types', action='append_const', const=str)
        parser.add_argument('--int', dest='types', action='append_const', const=int)
💻 Command
test.py
▶ Output
            Namespace(types=None)
💻 Command
test.py --str
▶ Output
            Namespace(types=[<class 'str'>])
💻 Command
test.py --str --int
▶ Output
            Namespace(types=[<class 'str'>, <class 'int'>])
📝
Naprosto neinvenčně (téměř) opsáno přímo z dokumentace.
24

action='version'

Při zadání příslušného přepínače vypíše hodnotu parametru version= na tomto argumentu. V nejjednodušším případě jako prostý řetězec..

💻 Command
test.py --version
📄 Program
            parser.add_argument('--version', action='version', version='2.1')
▶ Output
            2.1

..ale můžete použít i hodnoty nadefinované jinde:

💻 Command
test.py --version
📄 Program
            parser.add_argument('--version', action='version', version='%(prog)s 2.1')
▶ Output
            test.py 2.1
📝
A kdybyste potřebovali, jméno programu můžete zadat „natvrdo“ při zavádění parseru pomocí parser = ArgumentParser(prog='TestovaciProgram') .
25

Parametr „nargs“

Obecně určuje počet argumentů příslušejících pod stejné jméno příslušná akce (tj. parametr action) a většinou to znamená právě jednu hodnotu (a ve výchozím nastavení jako řetězec). Potřebujete-li ale jiné chování, parametr nargs umožňuje určit násobnost (počet výskytů) příslušného argumentu (převážně – ale ne vždy – přepínače). Pro rozlišení používá standardní označení N?*+, konkrétní chování však záleží na typu argumentu:

  • N – uvedený počet (N) argumentů z příkazové řádky bude složen dohromady do seznamu
  • ? – je-li přítomna, je z příkazová řádky načtena jedna hodnota
  • * – z příkazové řádky řádky jsou všechny odpovídající argumenty zahrnuty do jednoho seznamu
  • + – stejně jako *, ale narozdíl od ní je alespoň jeden argument vyžadován, jinak dojde k chybě
26

nargs=N

Složí uvedený počet (N) argumentů z příkazové řádky do seznamu: 

        parser.add_argument('-y', nargs=3)
💻 Command
test.py -y 1
▶ Output
            usage: test.py [-h] [-y Y Y Y]
            test.py: error: argument -y: expected 3 arguments
💻 Command
test.py -y 1 2 3
▶ Output
            Namespace(y=['1', '2', '3'])

Pozor – vytvoření seznamu se týká i jednoho argumentu!

💻 Command
test.py -x a
📄 Program
            parser.add_argument('-x', nargs=1)
▶ Output
            Namespace(x=['a'])
27

nargs='?'

Je-li na příkazové řádce přítomna, načte právě jednu hodnotu. Není-li, pak se chování liší podle typu parametru:

  • pro poziční argument doplní hodnotu z default
  • pro přepínač doplní hodnotu z const 
        parser.add_argument('-x', nargs='?', const='ahoj')
        parser.add_argument('file', nargs='?', default='text')
💻 Command
test.py
▶ Output
            Namespace(file='text', x=None)
💻 Command
test.py -x
▶ Output
            Namespace(file='text', x='ahoj')
💻 Command
test.py -x baf
▶ Output
            Namespace(file='text', x='baf')
💻 Command
test.py -x baf soubor
▶ Output
            Namespace(file='soubor', x='baf')

Typické použití u pozičních argumentů je například pro volitelné vstupní/výstupní soubory:

📄 Program
            parser.add_argument('infile', nargs='?', type=argparse.FileType('r'),
                                default=sys.stdin)
▶ Output
            Namespace(infile=<_io.textIOWrapper name='<stdin>' mode='r' encoding='UTF-8'>)
📝
Na základě experimentování typ FileType zjevně otevře uvedené soubory vždy v kódování UTF-8 nezávisle na platformě.
28

nargs='*'

Načte z příkazové řádky všechny odpovídající argumenty a zahrne je do jednoho seznamu. Ale když nakombinujete dohromady poziční argumenty a přepínače, musíte si dát pozor na jejich počet i pořadí: 

        parser.add_argument('-x', nargs='*')
        parser.add_argument('-y', nargs='*')
        parser.add_argument('file', nargs='*', default='text')
💻 Command
test.py
▶ Output
            Namespace(file1='text', x=None, y=None)
💻 Command
test.py -x 1 2 3
▶ Output
            Namespace(file='text', x=['1', '2', '3'], y=None)
💻 Command
test.py -x 1 2 3 -y a
▶ Output
            Namespace(file='text', x=['1', '2', '3'], y=['a'])
💻 Command
test.py vrr haf -x 1 2 3 -y a
▶ Output
            Namespace(file=['vrr', 'haf'], x=['1', '2', '3'], y=['a'])
29

nargs='+'

Parametr nargs='+' se chová z větší části stejně jako nargs='*', ale narozdíl od něj je alespoň jeden argument na vstupu vyžadován, jinak dojde k chybě: 

        parser.add_argument('-x', nargs='+')
        parser.add_argument('file', nargs='+', default='text')
💻 Command
test.py
▶ Output
            usage: test.py [-h] [-x X [X ...]] file [file ...]
            test.py: error: too few arguments
💻 Command
test.py vrr haf
▶ Output
            Namespace(file=['vrr', 'haf'], x=None)
💻 Command
test.py vrr haf -x
▶ Output
            usage: test.py [-h] [-x X [X ...]] file [file ...]
            test.py: error: argument -x: expected at least one argument
💻 Command
test.py vrr haf -x 1 2
▶ Output
            Namespace(file=['vrr', 'haf'], x=['1', '2'])

Parametr „const“

Jak jsme viděli na příkladu akcí store_const a append_const, určuje parametr const hodnotu, která bude uložena/přidána pod příslušné jméno: 

        parser.add_argument('-x', action='store_const', const='vrr')
💻 Command
test.py
▶ Output
            Namespace(x=None)
💻 Command
test.py -x
▶ Output
            Namespace(x='vrr')

Kromě toho pro přepínače s násobností ? (tedy nulakrát nebo právě jednou) dodává výchozí hodnotu, nejsou-li uvedeny: 

        parser.add_argument('-y', const='haf', nargs='?')
💻 Command
test.py
▶ Output
            Namespace(y=None)
💻 Command
test.py -y
▶ Output
            Namespace(y='haf')
💻 Command
test.py -y vrr
▶ Output
            Namespace(y='vrr')
31

Parametr „help“

Do parametru help se uvádí text, který se vypíše uživateli při vyžádání nápovědy (typicky tedy jako odpověď na -h nebo --help):

💻 Command
test.py -h
📄 Program
            parser.add_argument('-x', '--xhtml',
                                help='Proveď parsování podle standardu XHTML.')
▶ Output
            usage: test.py [-h] [-x XHTML]
            
            optional arguments:
              -h, --help            show this help message and exit
              -x XHTML, --xhtml XHTML
                                    Proveď parsování podle standardu XHTML.

Při zadávání (nejen) nápovědních textů můžete s výhodou využít některé předdefinované (rozuměno zavedením parseru) formátovací konstanty jako například:

  • %(prog)s – jméno skriptu (nebo hodnota parametru prog= na konstruktoru argparse.ArgumentParser())
  • hodnoty prakticky všech možných parametrů na metodě add_argument(), tj. %(prog)s, %(dest)s, %(nargs)s, %(const)s, %(default)s, %(type)s, %(choices)s a %(metavar)s (a dokonce i %(help)s :-)
32

Parametr „metavar“

Při výpisu nápovědy (jak v popisu usage: tak v celé nápovědě --help) jsou použita jistým způsobem upravená jména cílových proměnných pro jednotlivé argumenty:

💻 Command
test.py
📄 Program
            parser.add_argument('-x', '--xhtml', action='store_true')
            parser.add_argument('-n', '--numbers', nargs=3)
            parser.add_argument('file')
▶ Output
            usage: test.py [-h] [-x] [-n NUMBERS NUMBERS NUMBERS] file
            test.py: error: too few arguments

Tyto zobrazené názvy (a pouze je, nic jiného!) můžete změnit pomocí parametru metavar=:

💻 Command
test.py
📄 Program
            parser.add_argument('-x', '--xhtml', action='store_true')
            parser.add_argument('-n', '--numbers', nargs=3, metavar='N')
            parser.add_argument('file')
▶ Output
            usage: test.py [-h] [-x] [-n N N N] file
            test.py: error: too few arguments

Co je šikovné, tak v součinnosti s hodnotou parametru nargs můžete zadat metavars jako n-tici:

💻 Command
test.py
📄 Program
            parser.add_argument('-x', '--xhtml', action='store_true')
            parser.add_argument('-n', '--numbers', nargs=3, metavar=('N1', 'N2', 'N3'))
            parser.add_argument('file')
▶ Output
            usage: test.py [-h] [-x] [-n N1 N2 N3] file
            test.py: error: too few arguments
33

Skupiny argumentů

Ve výchozím nastavení rozděluje nápověda při výpisu argumenty na dvě skupiny – přepínače a poziční. Chcete-li, můžete si ale provést vlastní rozdělení do skupin za pomoci metody add_argument_group() příslušného parseru. Argumenty se pak přidávají místo parseru do těchto nově zavedených skupin:

💻 Command
python3 argparse_groups.py --help
📄 Program: argparse/argparse_groups.py
▶ Output
📝
Argumenty nepřiřazené explicitně do těchto nových skupin skončí na původních místech (tedy ve skupinách positional arguments a/nebo optional arguments).
34

Navzájem se vylučující argumenty

Někdy můžete potřebovat, aby z nějaké skupiny či skupin šel vybrat pouze a jenom právě jeden argument. argparse má pro tento případ k dispozici metodu add_mutually_exclusive_group(). Navzdory podobnosti s metodou add_argument_group() nevytváří (alespoň zatím) žádné v nápovědě viditelné skupiny – uvedené argumenty jsou pouze svázány poutem exkluzivity: 

        group1 = parser.add_mutually_exclusive_group()
        group1.add_argument("-x", action="store_true")
        group1.add_argument("-y", action="store_true")
        group1.add_argument("-z", action="store_true")
💻 Command
test.py -xyz
▶ Output
            usage: test.py [-h] [-x | -y | -z]
            test.py: error: argument -y: not allowed with argument -x
💻 Command
test.py -yz
▶ Output
            usage: test.py [-h] [-x | -y | -z]
            test.py: error: argument -z: not allowed with argument -y
💻 Command
test.py -z
▶ Output
            Namespace(x=False, y=False, z=True)

Zadání argumentu z exkluzivní skupiny lze vynutit pomocí parametru required=True:

💻 Command
test.py
📄 Program
            group1 = parser.add_mutually_exclusive_group(required=True)
            group1.add_argument("-x", action="store_true")
            group1.add_argument("-y", action="store_true")
▶ Output
            usage: test.py [-h] (-x | -y)
            test2.py: error: one of the arguments -x -y is required
35

Výchozí hodnoty argumentů

Argumenty mohou mít nějaku hodnotu, aniž bychom je vždy museli zadávat na příkazové řádce (pokud samozřejmě nepatří mezi argumenty vyžadované). Mohou ji získat:

  • při zavedení z parametru default= ;
  • z globálního nastavení pomocí metody parseru set_defaults().

Metoda set_defaults() zvítězí i nad parametrem default=, jak si snadno můžeme ověřit pomocí doplňkové metody get_default():

💻 Command
test.py -x 123
📄 Program
            parser.add_argument("-x", default="Monty")
            parser.add_argument("-y", default="Python")
            parser.set_defaults(y='not snake', z=42)
            
            args = parser.parse_args()
            print( args )
            
            print( 'x default:', parser.get_default('x') )
            print( 'y default:', parser.get_default('y') )
            print( 'z default:', parser.get_default('z') )
▶ Output
            Namespace(x='123', y='not snake', z=42)
            x default: Monty
            y default: not snake
            z default: 42
📝
Vlastnost výstupního objektu args.z v tomto kódu přitom není zadatelná z příkazové řádky! Má tedy právě tu hodnotu, na jakou ji set_defaults() nastaví.
36

Částečné zpracování

Díky metodě parse_known_args() umožňuje modul argparse zpracovat i příkazovou řádku, která obsahuje neznámé argumenty (na kterých by se metoda parse_args() s hláškou „unrecognized arguments“ zastavila). Vrací přitom dvojici, jejímž:

  1. prvním prvkem je standardní návratový objekt rozpoznaných argumentů;
  2. druhým prvkem je seznam nerozpoznaných argumentů.
💻 Command
test.py -y -t --baf=vrr
📄 Program
            parser.add_argument("-x", action="store_true")
            parser.add_argument("-y", action="store_true")
            
            args = parser.parse_known_args()
            print( args )
▶ Output
            (Namespace(x=False, y=True), ['-t', '--baf=vrr'])
