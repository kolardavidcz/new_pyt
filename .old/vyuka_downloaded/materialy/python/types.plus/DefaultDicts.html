Objekty „defaultdict“ – slovníky s výchozími hodnotami

by Jiří Znamenáček

1

Úvod

Klasický pythoní slovník můžete v principu vyrobit především následujícími dvěma metodami:

  • zavedením z iterovatelného objektu, který obsahuje logicky provázané dvojce klíč-hodnota (např. seznam dvojic), a to buď přímo v konstruktoru nebo nějakým cyklením přes tento iterovatelný objekt a postupným přidáváním jednotlivých dvojic;
  • zavedením z iterovatelného objektu obsahujícím pouze klíče – buď pomocí metody fromkeys(), kdy každý klíč dostane jednu konkrétní výchozí hodnotu, nebo můžete nasadit nějakou složitou rozhodovací mašinérii ve smyčce.

Type collections.defaultdict řeší právě tento druhý problém – jakou výchozí hodnotu přiřadit dosud neexistujícímu klíči.

2

Příklad – klasicky

Spočítejme výskyt jednotlivých písmen v textu: 

>>> xs = "abrakadabra"
>>> xd = {}
>>> for x in xs:
...   if x in xd:
...     xd[x] += 1
...   else:
...     xd[x] = 1
... 
>>> xd
{'b': 2, 'd': 1, 'r': 2, 'a': 5, 'k': 1}

Zde není co řešit – existuje-li již příslušný klíč ve slovníku, zvýšíme příslušný počet o jedničku, neexistuje-li, znamená to, že jsme na něj natrefili poprvé, a tak ho zavedeme s výchozí hodnotou 1. Průhledné a zdánlivě to už snáz nejde.

📝
PS: Pro tuto chvíli zapomeňme, že zrovna tuhle úlohu řeší elegantně typ collections.Counter.
3

Příklad – pomocí výjimek

Místo dotazování na existenci klíče můžeme také použít metodu „prostě to zkus a uvidíš“: 

        >>> xs = "abrakadabra"
        >>> xd = {}
        >>> for x in xs:
        ...     try:
        ...         xd[x] += 1
        ...     except KeyError:
        ...         xd[x] = 1
        >>> xd
        {'a': 5, 'b': 2, 'd': 1, 'k': 1, 'r': 2}

Výsledek je pochopitelně stejný.

4

Příklad – pomocí „defaultdict“

Nyní vyřešme předchozí úlohu pomocí defaultdict: 

>>> from collections import defaultdict
>>> xs = "abrakadabra"
>>> xd = defaultdict(int)
>>> for x in xs:
...   xd[x] += 1
... 
>>> xd
defaultdict(<class 'int'>, {'b': 2, 'd': 1, 'r': 2, 'a': 5, 'k': 1})

Zde je chování mnohem zajímavější – přidávací smyčka jakoby interně předpokládala, že příslušný klíč v poli už vždy existovat bude! A přesně to se také oklikou děje – pokud totiž pokus o přečtení hodnoty xd[x] (tedy vyhledání klíče x) selže, je automaticky vytvořen s hodnotou získanou zavoláním funkce předané jako vstupní parametr konstruktoru slovníku s výchozími hodnotami (zde int(), která vrací 0).

5

Zavedení

defaultdict je prakticky ve všem úplně stejný jako klasický slovník. Jedinou výjimkou je právě první parametr konstruktoru, kterým je odkaz na vytvořující funkci (a pak už může následovat klasický iterovatelný objekt jako u xd = dict(ITERABLE)):

xd = collections.defaultdict([default_factory[, ITERABLE]])

Neuvedení prvního parametru nastaví vlastnost xd.default_factory na None a jakýkoliv neexistující klíč pak vyhodí výjimku KeyError. Takže ve většině případů má větší smysl tam skutečně referenci na nějakou funkci uvést ^_^ Přitom tou funkcí může s výhodou být třebas i lambda-funkce, jak ukazuje přepis předchozího příkladu: 

        >>> xs = "abrakadabra"
        >>> xd = defaultdict(lambda: 0)
        >>> for x in xs:
        ...   xd[x] += 1
        ... 
        >>> xd
        defaultdict(<function <lambda> at 0x7fc74581ea60>, {'b': 2, 'd': 1, 'r': 2, 'a': 5, 'k': 1})
6

Srovnání se „setdefault()“

Poněkud staršího data je metoda slovníku setdefault(), která také umožňuje nastavit hodnotu pro neexistující klíč, ale dle mého názoru velmi kriptickým způsobem a navíc je zrovna tímto způsobem použitelná pouze pro typy s metodami: 

        # vstupní data
        >>> xs = [('yellow', 1), ('blue', 2), ('yellow', 3), ('blue', 4), ('red', 1)]
        
        # a) slovník pomocí „setdefault()“
        >>> xd = {}
        >>> for k, v in xs:
        ...   xd.setdefault(k, []).append(v)
        ... 
        >>> xd
        {'red': [1], 'blue': [2, 4], 'yellow': [1, 3]}
        
        # b) slovník pomocí „defaultdict“
        >>> xd = defaultdict(list)
        >>> for k, v in xs:
        ...   xd[k].append(v)
        ... 
        >>> xd
        defaultdict(<class 'list'>, {'red': [1], 'blue': [2, 4], 'yellow': [1, 3]})
📝
Opsáno z dokumentace.

Na druhou stranu se narozdíl od defaultdict() konstruktor výchozí hodnoty u setdefault() volá pro každý dosud neexistující klíč znovu během vykonávání smyčky for-in, takže ho třeba můžete průhledně učinit závislým na klíči a podobně.

📝
A také díky tomu bude pomalejší, ale ne že by to u Python'u hrálo zase až takovou roli.

PS: Je tu ještě jeden drobný rozdíl – zatímco u defaultdict() je vytvořující funkce pro všechny neznámé klíče stejná, u setdefault() ji můžete zvolit nezávisle pro každý klíč jinak v okamžiku použití (ne tedy zrovna takhle jednoduše uvnitř smyčky).

7

Poznámky

Jako vytvořující funkce se často používají vestavěné konstruktory jako list, set, dict nebo int. Výhodou defaultdictu však je, že v použité funkci se můžete docela vyřádit: 

        >>> from collections import defaultdict
        >>> xs = "abrakadabra"
        >>> xd = defaultdict(
              lambda: ['samohláska', 0] if x in 'aeiouy' else ['souhláska', 0]
            )
        >>> for x in xs:
        ...   xd[x][1] += 1
        ... 
        >>> xd
        defaultdict(<function <lambda> at 0x7fc7473b96a8>,
          {'b': ['souhláska', 2], 
           'd': ['souhláska', 1],
           'r': ['souhláska', 2],
           'a': ['samohláska', 5],
           'k': ['souhláska', 1]}
        )
📝
(Pozalamováno pro lepší čitelnost.)

Všimněte si ale, že vytvořující funkce obdržela proměnnou klíče x automaticky z okolního kontextu!

📝
Což je víc než hloupé, protože to x ve for-in a if-in bohužel není jen pouhá shoda jmen proměnných – lambda-funkce musí opravdu odkazovat na již existující příslušnou proměnnou cyklu :-(

setdefault() se v tomto případě chová výrazně rozumnějí, protože klíč získává hodnotu předáním jako argument funkce: 

        >>> def fn(k):
        ...     return ['samohláska', 0] if k in 'aeiouy' else ['souhláska', 0]
        >>> xe = {}
        >>> for x in "abrakadabra":
        ...     xe.setdefault(x, fn(x))[1] += 1
        >>> xe
        {'a': ['samohláska', 5],
         'b': ['souhláska', 2],
         'd': ['souhláska', 1],
         'k': ['souhláska', 1],
         'r': ['souhláska', 2]}

Chcete-li se tudíž ve vytvořující funkci jaksepatří „vyřádit“, je setdefault() lepší volba.
