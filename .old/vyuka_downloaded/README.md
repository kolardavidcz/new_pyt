# Offline Course Materials: Python (VŠCHT ZS 2025/2026)

This folder contains a complete offline download of the lecture slides, exercises, and code examples from Jiří Znamenáček's course page at http://vyuka.ookami.cz/.

## How to use:
1. Open the main offline entry point: [index.html](index.html) in your browser.
2. Navigate to any of the slide sections under **Přednášky**, **Přednášky PLUS**, or **Příklady**.
3. All local XML files, code scripts, and images have been downloaded recursively and mirror the original site layout.

## Structure:
- `materialy/` - Slide materials, lectures, and guides (.xml files, images).
- `priklady/` - Practice problems and exercises.
- `cjs/` - Stylesheets and scripts for rendering.
- `index.html` - The course homepage with links to all local files.
