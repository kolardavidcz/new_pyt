Třídění

by Jiří Znamenáček

1

Úvod

Python má zabudovaný algoritmus pro třídění TimSort, který je poměrně univerzální, rychlý a hlavně stabilní, takže se dá použít pro vícenásobné třídění objektů podle více kritérií (byť zrovna tohle není příliš potřeba).

PS: Dvojkový Python používal při řazení standardní porovnávací funkci cmp(x1, x2), kterou znáte snad z většiny ostatních programovacích jazyků. Trojkový ji zaměnil za řazení pomocí klíče, které je asi dosti nezvyklé, ale (nejen) podle mého velmi mocné.

2

Třídění vestavěných typů – „sorted()“

Primárním způsobem třídění je použití globální funkce sorted(): 

    xs = sorted(iterable[, key][, reverse])

Ta dokáže nějakým způsobem setřídit každý iterovatelný typ, který se nějak setřídit dá, přičemž vrací seznam: 

>>> xs = { 'b': 2, 'a': 1, 'c': 9, 'd': 7, }

>>> ys = sorted(xs)
>>> ys
['a', 'b', 'c', 'd']
📝
Zde tedy metoda sorted() setřídila slovník a to tak, jak je pro slovník typické – po klíčích.
3

Poznámka k seznamům – metoda „[].sort()“

Pro řazení objektů typu seznam můžeme též použít metodu sort(): 

    xs.sort([key[, reverse]])

Ta řadí seznam „v místě“, tzn. že nevytváří nový objekt, do kterého by nakopírovala výsledek řazení jako metoda sorted(), ale místo toho upraví pořadí prvků v tříděném seznamu (takže o seznam s původním pořadím prvků tímto přijdeme): 

>>> xs = [5, 2, 6, 4, 1, 3, ]

>>> xs.sort()
>>> xs
[1, 2, 3, 4, 5, 6]
📝
Aby dala ještě více najevo, že objekty jsou řazeny „v místě“, vrací metoda xs.sort() None.
4

Parametr „reverse“

Nepovinný boolean-parametr reverse u obou třídících metod nastavením na True způsobí změnu směru řazení (vlastně provádí všechna porovnávání opačně): 

>>> xs = [5, 2, 6, 4, 1, 3, ]

>>> xs.sort( reverse=True )
>>> xs
[6, 5, 4, 3, 2, 1]

PS: V dalším textu ho, a stejně tak i metodu seznamu sort(), budeme ignorovat a probereme důkladně pouze druhý pojmenovaný parametr key a logiku schovanou za vlastním tříděním.

5

Třídění je lexikografické I

Objekty v Python'u se třídí podle svého typu: 

# třídění čísel podle velikosti
>>> sorted( [1, 5, 3, 2, 4, ] )
[1, 2, 3, 4, 5]

# třídění řetězců podle abecedy..
>>> sorted( ['ovce', 'kočka', 'pes', 'hroznýš', 'prase', ] )
['hroznýš', 'kočka', 'ovce', 'pes', 'prase']

# ..ovšem unicodové
>>> sorted( ['jedna', 'dvě', 'tři', 'čtyři', 'pět', 'šest', 'sedm', ] )
['dvě', 'jedna', 'pět', 'sedm', 'tři', 'čtyři', 'šest']
6

Třídění je lexikografické II

Složitější objekty se pak třídí postupně po jednotlivých částech, přičemž každý „základní/jednoduchý“ typ se třídí stejně jako výše: 

>>> sorted( [('two', 3), ('one', 4), ('one', 2), ('three', 5), ('two', 1), ] )
[('one', 2), ('one', 4), ('three', 5), ('two', 1), ('two', 3)]
📝
Tzn. že n-tice v seznamu se nejdříve setřídily podle své první položky, tj. abecedně, a poté takto shodné ještě navíc i podle druhé, tj. podle velikosti.
7

Třídění je lexikografické III

Lexikografické třídění tedy znamená, že např. čísla se seřadí podle velikosti a řetězce podle abecedy plus to, že sekvence se porovnávají postupně „po složkách“ (pokud jsou ovšem typy příslušných složek navzájem porovnatelné). Přitom o výsledku řazení rozhodne první dvojce (libovolně hluboko zanořených) prvků, která není stejná, jak ukazuje následující příklad: 

>>> [1, 2] < [1, 2, 3]
True

>>> [1, ['a', 'b']] < [1, ['a', 'b'], 3]
True

>>> [1, ['a', 'c']] < [1, ['a', 'b'], 3]
False
📝
Jelikož 'c' > 'b', tak se Python skutečně nedívá na to, že druhá sekvence je delší – první sekvence zvítězila, protože řazení natrefilo na první dvojci porovnatelných prvků, která už rozhodla o výsledku.
8

Porovnávání různých typů

Typy musejí být porovnatelné, jinak obdržíte výjimku TypeError: 

>>> 3.5 < 4
37: True

>>> 'a' < 'c'
37: True

>>> 'a' < 5
Traceback (most recent call last):
  File "<pyshell#51>", line 1, in <module>
'a' < 5
TypeError: unorderable types: str() < int()

A zdůrazňuji – ne nutně stejné, ale pouze porovnatelné! Pokud poskytují podporu pro porovnávání se i s jiným typem, tak se bez řečí porovnají.

📝
Jak ukazují třebas výše celá a reálná čísla – to jsou také různé typy, ale má smysl je porovnávat.
9

Další příklady

Ještě několik příkladů z dokumentace pro zmatení nepřítele: 

# protože 3 < 4:
>>> (1, 2, 3, 4) < (1, 2, 4)
True

# protože první sekvence je počáteční podsekvencí druhé:
>>> (1, 2) < (1, 2, -1)
True
10

Magický parametr „key“

Třídění můžeme vnutit, aby se chovalo jinak, než by pro daný typ bylo běžné. To zajišťuje nepovinný pojmenovaný parametr key, který specifikuje funkci, která bude před vlastním porovnáváním zavolána na každý prvek vstupního iterovatelného typu.

Nejsnažší je využití již známé funkce, jako např. len(): 

>>> names = [ "John", "Wendy", "Pete", "Jane", "David", "Amanda", "Ix"]
>>> sorted( names, key=len )
['Ix', 'John', 'Pete', 'Jane', 'Wendy', 'David', 'Amanda']
📝
Zde je každý prvek vstupního seznamu, tedy řetězec, převeden na svou délku (ve znacích) a teprve podle ní je porovnán.
11

„key“ a lambda-funkce I

Nestačí-li nám předdefinované funkce, můžeme s výhodou pro třídění použít vlastní funkce řádkové, tzv. lambda-funkce: 

>>> xs = [('two', 3), ('one', 4), ('one', 2), ('three', 5), ('two', 1), ]
>>> sorted( xs, key=lambda x: x[1] )
[('two', 1), ('one', 2), ('two', 3), ('one', 4), ('three', 5)]

Zde jsme místo výchozího lexikografického porovnání vnutili třídění podle druhé části (x[1]) každého prvku vstupního seznamu.

📝
Lambda-funkce je prostě funkce beze jména, zavedená v rámci jednoho výrazu. Použití nachází mimo jiné všude tam, kde je potřeba funkci, ale je zbytečné kvůli tomu „zaneřáďovat“ globální jmenný prostor. V Python'u se nejčastěji vyskytují právě zde, u řazení.
12

„key“ a lambda-funkce II

Složitější příklad: 

>>> names = [ "John", "Wendy", "Pete", "Jane", "David", "Amanda", "Ix"]

# A) setřídění pouze podle délky slov
>>> sorted(names, key=len)
['Ix', 'John', 'Pete', 'Jane', 'Wendy', 'David', 'Amanda']

# B) setřídění navíc i podle abecedy
>>> sorted(names, key=lambda x: (len(x), x))
['Ix', 'Jane', 'John', 'Pete', 'David', 'Wendy', 'Amanda']

Zde parametr key v podstatě vyrobil z původního seznamu řetězců seznam n-tic [(4, 'John'), (5, 'Wendy'), (4, 'Pete'), (4, 'Jane'), (5, 'David'), (6, 'Amanda'), (2, 'Ix'), ], který následně lexikograficky setřídil a zpětně z něj vyextrahoval prvky původního seznamu.

📝
Ve starších verzích Python'u byste si tento upravený „meziseznam“ i extrakci setříděných prvků museli zařídit sami (viz tzv. metoda DSO, „decorate-sort-undecorate“).
13

Poznámka

Jelikož pro řazení můžeme použít odkaz na libovolnou funkci, přepišme si poslední příklad tak, aby bylo lépe vidět, co se při řazení uvnitř děje: 

>>> names = [ "John", "Wendy", "Pete", "Jane", "David", "Amanda", "Ix"]

# Nejdřív to samé pomocí voastní funkce:
>>> def porovnej(x):
...   return len(x), x
... 
>>> sorted(names, key=porovnej)
['Ix', 'Jane', 'John', 'Pete', 'David', 'Wendy', 'Amanda']

# Nyní si přidáme výpis parametrů:
>>> def porovnej(x):
...   print(x)
...   return len(x), x
... 
>>> sorted(names, key=porovnej)
John
Wendy
Pete
Jane
David
Amanda
Ix
['Ix', 'Jane', 'John', 'Pete', 'David', 'Wendy', 'Amanda']

Python tedy za pomoci funkce porovnej() převedl každý prvek vstupní sekvence na dvojci (len(x), x), kterou použil pro lexikografické setřídění původních dat.

14

Modul „operator“

Třídění podle vybrané části složitějšího objektu je natolik častý obrat, že Python poskytuje v rámci modulu operator několik pomocných funkcí, které nám ušetří psaní výběrových lambda-funkcí: 

>>> xs = [('two', 3), ('one', 4), ('one', 2), ('three', 5), ('two', 1), ]

# A) výchozí lexikografické třídění
>>> sorted(xs)
[('one', 2), ('one', 4), ('three', 5), ('two', 1), ('two', 3)]

# B1) třídění za pomoci výběrové lambda-funkce
>>> sorted(xs, key=lambda x: x[1])
[('two', 1), ('one', 2), ('two', 3), ('one', 4), ('three', 5)]

# B2) totéž, ale za pomoci metody itemgetter()
>>> from operator import itemgetter
>>> sorted(xs, key=itemgetter(1))
[('two', 1), ('one', 2), ('two', 3), ('one', 4), ('three', 5)]

Modul operator poskytuje i další metody, které se uplatní zvláště u třídění instancí objektů: operator.attrgetter(), operator.methodcaller()

15

Stabilita třídění I

Všimněme si ještě jednou příkladu: 

>>> names = [ "John", "Wendy", "Pete", "Jane", "David", "Amanda", "Ix"]
>>> sorted( names, key=len )
['Ix', 'John', 'Pete', 'Jane', 'Wendy', 'David', 'Amanda']

Jelikož porovnávací funkcí je len(), tedy délka řetězce, provede Python na vstupním objektu jen tolik změn, kolik je nezbytně nutné. Ve výsledku si čtyřpísmenná ('John', 'Pete', 'Jane') i pětipísmenná ('Wendy', 'David') slova zachovají stejné pořadí jako na vstupu.

📝
Nezapomeňte – provedli jsme srovnání podle délky, nikoli abecedy!
16

Stabilita třídění II

Stability se dá využít pro třídění podle více kritérií – postupně provedeme třídění od posledního požadavku po první.

Například studenty podle známky a poté podle věku setřídíme následovně.. 

# ('jméno', 'známka', věk)
>>> xs = [ ('Petr', 'A', 23), ('Bořek', 'A', 21), ('Pavel', 'B', 21), ]

# a) nejdříve provedeme třídění podle věku..
>>> s = sorted(xs, key=lambda x: x[2])
>>> s
[('Bořek', 'A', 21), ('Pavel', 'B', 21), ('Petr', 'A', 23)]

# b) ..a poté podle známky
>>> sorted(s, key=lambda x: x[1])
[('Bořek', 'A', 21), ('Petr', 'A', 23), ('Pavel', 'B', 21)]

..ale asi je mnohem pochopitelnější a přímočařejší zavolat rovnou: 

    sorted( xs, key=lambda x: (x[1], x[2]) )
17

Poznámky

  • Výchozí porovnávání objektů využívá jejich metodu __lt__(), je-li k dispozici. Jejím definováním tudíž můžeme předepsat, jak se naše objekty budou mezi sebou porovnávat (viz samostatná přednáška).
  • Pokud všechny prvky určené pro třídění podporují požadované třídicí kritérium, nemusí pochopitelně vůbec být stejného typu: 
    >>> sorted(
                ['Ahoj!', [1, 2, 3, 'Baf!'], {'já', 'množina', '∞'}, ('xxx', 666)],
                key=len
            )
            [('xxx', 666), {'já', '∞', 'množina'}, [1, 2, 3, 'Baf!'], 'Ahoj!']
  • Funkce vstupující do parametru key vůbec nemusí operovat na porovnávaných objektech. Má-li to smysl, může hodnoty pro třídění brát úplně odjinud.
18

Poznámky k národním zvyklostem

Třídění můžeme vnutit ohled na národní zvyklosti pomocí metody key=locale.strxfrm z modulu locale. Což podle aktuálního nastavení systému sice může zafungovat rovnou, ale chcete-li přenositelný kód, musíte použité pravidlo nejdříve nastavit pomocí locale.setlocale(). V posledních verzích Python'u se mi pro češtinu osvědčilo nastavení: 

>>> locale.setlocale(locale.LC_ALL, ('czech', 'UTF-8'))
        'cs_CZ.UTF-8'
>>> sorted('koníček', key=locale.strxfrm)
        ['č', 'e', 'í', 'k', 'k', 'n', 'o']
📝
Byť má tedy své mouchy – takové ň se s ním moc dobře neřadí. Ale pořád lépe než bez něj.

Použití globálního LC_ALL zařídí, že se pravidla třídění uvedeného jazyka použijí úplně pro všechno, tedy nejen slova, ale třeba i čísla, datumy, měnu a podobně.

📝
Použít proto pouze locale.setlocale(locale.LC_ALL, ''), který přebere nastavení jednotlivých položek ze systému, není nejlepší nápad – jste si jisti, že pro všechno máte nastavený stejný jazyk? ^_~

PS 1: Pravidlo pro řazení se dá nastavit kromě výše uvedené plné verze i pomocí zkratky, jejich seznam je k dispozici v locale.locale_alias. Nicméně to kupodivu není příliš přenositelné.

📝
Například locale.setlocale(locale.LC_ALL, 'czech') zabere na Windows, ale pod Linuxem už ne, ačkoli příslušný alias existuje i tam. (Ale možná mám jen všechny linuxy stejně divně nastavené?)

PS 2: locale.strxfrm() můžete použít také jako funkci obalující řetězec, který požadujete setřídit národním způsobem. Výhodné obzvláště u složených třídicích výrazů (= návratových n-tic), kde pouze jejich část jsou řetězce.
