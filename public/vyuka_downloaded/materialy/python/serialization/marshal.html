Serializace – „marshal“

by Jiří Znamenáček

1

Úvod

Prakticky jedinou úlohou modulu marshal je převod bajtkódu do/z předkompilovaných pyc-souborů.

Z těchto důvodů není jeho formát úmyslně ani nijak oficiálně dokumentovaný, aby někdo neměl tendenci používat ho místo modulů pickle, respektive shelve.

2

Metody modulu „marshal“

Modul marshal umí maršalovat a odmaršalovávat pomocí dvou skupin metod:

  • metody pro převod mezi pythonovskou strukturou a jí odpovídajícím zamaršalovaným řetězcem:
    • mo = marshal.dumps(o) – zamaršaluje hodnotu o do bajtového řetězce mo
    • o = marshal.loads(mo) – převede binární zamaršalovaný řetězec na jemu odpovídající pythonovskou hodnotu o
    📝
    Všimněte si koncového s u metod pro práci s binárními řetězci.
  • metody pro čtení/zápis z/do proudu:
    • marshal.dump(o, file) – zamaršaluje hodnotu o do binárního souboru file
    • o = marshal.load(file) – převede zamaršalovaný objekt z binárního souboru file na jemu odpovídající pythonovskou hodnotu o
📝
file je objekt typu stream, tj. file = open('soubor', 'rwb'), nikoli cesta k souboru.
📝
dump-metody mají nepovinný parametr version (verze maršalovacího protokolu), ale ten vám v podstatě může být ukradený.
3

Co lze zamaršalovat

Zamaršalovat jde především:

  • objekt bajtkódu (který můžete získat např. pomocí funkce compile())

Ale stejně tak se dají zamaršalovat i následující typy:

  • jednoduché typy – bool, int, float, complex, str, bytes, bytearray
  • složené typy – tuple, list, set, frozenset, dict (ale pouze tehdy, pokud obsahují podporované typy)
  • sigletony – None, Ellipsis, StopIteration
📝
Pokus o zamaršalování rekurzivního seznamu, množiny nebo slovníku způsobí nekonečnou smyčku.
4

Příklad – bajtkódobjekt

>>> co = compile("xs = (1, 2, 3)", "", "exec")
>>> co
<code object <module> at 0x00AD3C50, file "", line 1>

Příklad – data

>>> xs = (1, 2, 3)

>>> mo = marshal.dumps(xs)
>>> mo
   b'(\x03\x00\x00\x00i\x01\x00\x00\x00i\x02\x00\x00\x00i\x03\x00\x00\x00'

>>> marshal.loads(mo)
   (1, 2, 3)
6

Verze protokolu

Toho času (Python 3.2) je maršalovací protokol již ve své třetí verzi:

  • formát 0 – historický formát
  • formát 1 – internované řetězce jsou sdílené
  • formát 2 – používá binární formát pro zachycení reálných čísel

Verzi formátu můžete zjistit dotazem na marshal.version.

7

Poznámky

Maršalovací formát není nijak zabezpečen proti nebezpečným datům =>

Nikdy neodmaršalovávejte cizí data!

A vůbec – modul marshal je skutečně určen jen a pouze pro práci se soubory *.pyc, takže ho radši vážně nezkoušejte nasadit někde jinde.
