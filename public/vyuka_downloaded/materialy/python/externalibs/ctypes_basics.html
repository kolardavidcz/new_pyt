Modul „ctypes“

by Jiří Znamenáček

1

Úvod

Modul ctypes mimo jiné umožňuje volat funkce ze sdílených knihoven, nejen k čemuž především poskytuje typy kompatibilní s Céčkem. Nejsnažší je sice celkem pochopitelně práce s knihovnami napsanými v jazyce C, resp. C++, ale je možné obsluhovat i jiné jazyky, pokud nějakým způsobem poskytují s Céčkem kompatibilní rozhraní.

Typicky se používá právě pro volání funkcí cizích knihoven přímo z Python'u nebo rovnou pro psaní kompletních pythoních „wrapperů“ nad těmito knihovnami.

📝
Příkladem budiž třeba PyLeptonica, která slouží k obsluze céčkovské knihovny Leptonica pro práci s obrázky.
2

S Python'em kompatibilní typy

Vzhledem k rozdílnosti typů mezi Python'em a Céčkem lze přímo předávat (a vracet) pouze následující čtyři základní typy:

  • None;
  • celá čísla (int);
  • řetězce ("");
  • bajtové řetězce (b"").

Jakékoliv jiné typy, ať už jednoduché nebo složené, musí být zavedeny pomocí příslušných konstruktorů z modulu ctypes.

Důležité poznámky

Funkce a proměnné parametry:
Ačkoli jsou nativní (jednoduché) typy modulu ctypes proměnné (mutable), nemůžete je v této podobě použít u funkcí, které očekávají na vstupu ukazatel(e) na proměnné bloky paměti. Pro tyto případy slouží funkce create_string_buffer(), která vrací ctypes-pole typů c_char, respektive funkce create_unicode_buffer(), která vrací ctypes-pole typů c_wchar.
Volání funkcí:
Ačkoli se ctypes snaží ošetřit všelicos, zavolat funkci ze sdílené knihovny se špatnými parametry je nejlepší cesta jak vyrobit segmentation fault…
Na Windows je to trochu snažší, protože modul ctypes na nich dokáže zachytit výjimky týkající se špatných parametrů – malý nebo naopak velký počet, špatná hodnota apod. Ve výsledku vás ale nezachrání stejně nic :-)
5

Volání funkcí – typy argumentů „argtypes“

Sdílenou funkci musíte tedy samozřejmě zavolat se správnými typy parametrů. To můžete zařídit buď jejich explicitním přetypováním při každém volání nebo lépe vyjmenováním příslušných typů v seznamu atributu argtypes: 

>>> from ctypes import CDLL, c_char_p, c_int, c_double
>>> libc = CDLL('libc.so.6')
>>> printf = libc.printf
        
        # a) explicitní přetypování
>>> printf(b"String '%s', Int %d, Double %f\n", b"Hi", 10, c_double(2.2))
        String 'Hi', Int 10, Double 2.200000
        37

        # b) označení typů „dopředu“
>>> printf.argtypes = [c_char_p, c_char_p, c_int, c_double]
>>> printf(b"String '%s', Int %d, Double %f\n", b"Hi", 10, 2.2)
        String 'Hi', Int 10, Double 2.200000
        37

Uvedený způsob volání vás pak zachrání při pokusu předat špatné typy: 

>>> printf(b"%d %d %d", 1, 2, 3)
        Traceback (most recent call last):
          File "<stdin>", line 1, in <module>
        ctypes.ArgumentError: argument 2: <class 'TypeError'>: wrong type

Argumenty funkcí – „_as_parameter_“

Práci s parametry si můžete na jednu stranu zesložitit, ale na druhu také zpřehlednit, použitím tříd s atributem _as_parameter_ (ať už datovým nebo ne). Modul ctypes se totiž po tomto parametru bude koukat, použijete-li při volání instanci takové třídy: 

>>> import ctypes
>>> libc = ctypes.CDLL('libc.so.6')
>>> libc
        <CDLL 'libc.so.6', handle 7f45598819b0 at 7f45596b09e8>
>>> printf = libc.printf
>>> printf
        <_FuncPtr object at 0x7f45596c6048>
        
>>> class Bottles():
...     def __init__(self, number):
...         self._as_parameter_ = number
... 
>>> bottles = Bottles(42)
        
>>> printf(b"%d bottles of beer\n", bottles)
        42 bottles of beer
        19
>>> o = printf(b"%d bottles of beer\n", bottles)
        42 bottles of beer
📝
Bez invence přímo podle dokumentace.

PS: Rozumí se samo sebou, že uvedený parametr musí vracet buď celé číslo nebo řetězec (i bajtový).

7

Argumenty funkcí – „from_param()“

Chcete-li podobným způsobem použít vlastní třídy uvnitř seznamů pro atribut argtypes, musíte na nich nadefinovat metodu from_param(), která se postará o ověření správnosti typu a vrácení příslušné návratové hodnoty (klidně opět v podobě atributu objektu _as_parameter_): 

>>> import ctypes
>>> libc = ctypes.CDLL('libc.so.6')
>>> printf = libc.printf

>>> class Bottles():
...     def __init__(self, number):
...         self.number = number
...     @classmethod
...     def from_param(cls, obj):
...         print(obj)  # instance `bottles`
...         return obj.number
... 
>>> printf.argtypes = [ctypes.c_char_p, Bottles]
>>> bottles = Bottles(42)

>>> printf(b"%d bottles of beer\n", bottles)
        42 bottles of beer
        19
📝
Za pomoci Python Enums, ctypes.Structures, and DLL exports.

Tělo metody from_param() může být samozřejmě mnohem složitější a můžete se v něm třebas v rámci podmínky rozhodovat podle aktuálního tvaru parametrů a vracet v každé větvi něco jiného.

Volání funkcí – typ návratové hodnoty „restype“

Podobně se ve výchozím nastavení od sdílených funkcí čeká, že spořádaně vrátí Céčkovské celé číslo (int). Není-li tomu tak, musíte správný typ nastavit pomocí atributu restype: 

>>> from ctypes import CDLL, c_char, c_char_p, c_int, c_double
>>> libc = CDLL('libc.so.6')
>>> strchr = libc.strchr
        
>>> strchr.argtypes = [c_char_p, c_char]
>>> strchr.restype = c_char_p
>>> strchr(b"abcdef", b"d")
        b'def'

Předávání ukazatelů (pointerů)

Často se může stát, že volaná „cizí“ funkce bude očekávat parametry předávané odkazem (typicky byla-li by předávaná data zbytečně veliká na předání hodnotou a podobně). V takovém případě máte dvě možnosti:

  • nepotřebujete-li uvedenou referenci i ve vašem pythoním kódu, zabalte proměnnou při volání do funkce ctypes.byref();
  • potřebujete-li naopak referenci i v pythoním kódu, použijte skutečný konstruktor pointeru ctypes.pointer().

Nepřekvapivě je druhá možnost náročnější a pomalejší, protože toho prostě musí na pozadí udělat mnohem více.
