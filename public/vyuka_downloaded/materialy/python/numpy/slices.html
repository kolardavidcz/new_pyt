Výřezy pro pokročilé

by Jiří Znamenáček

1

Úvod

Ačkoli Python žádná vícerozměrná pole neobsahuje, balíček Numpy je zvládá bravurně. Leckoho už asi napadlo, jak je to vůbec možné – copak instalace externího balíčku může změnit chování jazyka na tak nízké úrovni? Pravda je ale jiná a asi trochu překvapivá:

Python obsahuje syntaktickou podporu (nejen) pro vícerozměrná pole a matice, ačkoli ji sám (skoro) nikde nevyužívá.

Numpy (a jiní) tak pouze využívá možností, které mu jazyk nabízí. Byť tyto možnosti jsou v Python'u často právě proto, že je Numpy potřeboval ^_^"

2

Výřezy a „__getitem__()“

Začněmež od píky – výběrem i-tého prvku ze sekvence. O ten se stará magická metoda __getitem__(), jak si můžeme snadno ukázat: 

>>> class Test:
...     def __getitem__(self, arg):
...         print(arg)
... 
... test = Test()

>>> test[1]
1
>>> test[1:]
slice(1, None, None)
>>> test[1:3]
slice(1, 3, None)
>>> test[1:3:2]
slice(1, 3, 2)
📝
Inspirace: Multi dimensional (axial) slicing in Python

Jakmile obsahuje výřez dvojtečku (tedy :; anglicky se takovému výřezu většinou říká extended slicing syntax), obdrží metoda __getitem__() místo pořadového čísla požadovaného prvku instanci objektu slice, která v sobě zahrnuje všechny tři možné parametry výřezové notace (ať už jsou všechny použity nebo ne).

3

Objekt „slice“

Objekt slice se sám o sobě prakticky moc nepoužívá, je to v podstatě především interní reprezentace výřezové notace. Ovšem použít se dá: 

>>> xs = [1, 2, 3, 4, 5, 6, 7]

>>> xs[2:5]
0: [3, 4, 5]

>>> xs[slice(2, 5, None)]
1: [3, 4, 5]

Jsou situace, kde to má dokonce smysl (především tedy u Numpy).

📝
A mimochodem -- třetí parametr ve výřezu je v Python'u také původně jenom kvůli Numpy a Python sám ho z počátku nikde nepoužíval ^_~
4

Osy výřezu

To nejzajímavější nás ovšem teprve čeká. Python totiž umožňuje napsat třebas i následující výřez: 

>>> class Test:
...     def __getitem__(self, arg):
...         print(arg)
... 
... test = Test()

>>> test[1, 3]
(1, 3)
>>> test[1:, :3]
(slice(1, None, None), slice(None, 3, None))
>>> test[1:3, 3:4]
(slice(1, 3, None), slice(3, 4, None))
>>> test[1:3:2, 3:4:2]
(slice(1, 3, 2), slice(3, 4, 2))

Což můžeme shrnout jako:

Výřezů za sebou můžete napsat více, a to oddělených čárkou. Každý z těchto výřezů se stane samostatnou tzv. osou výřezu, tedy prvkem příslušné n-tice výřezu.

To jste asi nečekali – všechny výřezy ve standardním Python'u jsou totiž pouze jednoosové! Python však umožňuje použít os více a z jednoho návratového prvku (ať už to bylo číslo, instance objektu slice nebo cokoliv jiného) se pak stane n-tice – co osa, to její další prvek. Jen snad žádný z vestavěných objektů ani Python'u samotného, ani jeho standardní knihovny, uvedenou vlastnost nepoužívá. Až právě na vícerozměrná pole v Numpy.

5

Vynechání části výřezu

Překvapením ale ještě není konec ^_~ U vícerozměrných polí (ale samozřejmě nejen tam) totiž začíná mít smysl vynechat z požadavku nepotřebné části dotazu, aby se člověk zbytečně moc neupsal: 

>>> class Test:
...     def __getitem__(self, arg):
...         print(arg)
... 
... test = Test()

>>> test[1, 3, ...]
(1, 3, Ellipsis)
>>> test[1, ..., 7]
(1, Ellipsis, 7)
>>> test[1:, ...]
(slice(1, None, None), Ellipsis)
>>> test[1:, ..., 7]
(slice(1, None, None), Ellipsis, 7)
>>> test[1:, ..., ::-2]
(slice(1, None, None), Ellipsis, slice(None, None, -2))

Neboli:

Vynechané části víceosového výřezu je možno označit pomocí speciální výpustkové notace ... (tedy opravdu doslova a dopísmene tří teček).

Co přesně s výpustkami implementace udělá, už je samozřejmě na ní. Numpy je používá pro označení „chybějících“ dimenzí.

6

Objekt „Ellipsis“

Podobně jako u objektu slice můžete i výpustky použít přímo, byť je to opět velmi nečastá operace: 

>>> class Test:
...     def __getitem__(self, arg):
...         print(arg)
... 
... test = Test()

>>> test[1, ...]
(1, Ellipsis)
>>> test[1, Ellipsis]
(1, Ellipsis)
7

Dodatek

slice je „obyčejný“ objekt, takže ho můžete použít všude tam, kde byste použili jiné objekty. Pokud to má smysl samozřejmě.

Ellipsis je předdefinovaná „konstanta“ reprezentující jedinou (povolenou) instanci typu ellipsis (mající stejný význam jako speciální notace ...), takže ji můžete použít také skoro všude. A podobně jako u slice to ne všude má smysl.

📝
No a jako skoro všechno v Python'u můžete jak slice, tak Ellipsis, přiřadit jiný význam. Vřele nedoporučuji ^_~ U ... to nejde, to je speciální notace rozpoznávaná interpretrem.
8

Poznámka

Numpy používá k indexování vícerozměrných polí čísla, slice-objekty a výpůstky. Python pak pro běžnou výřezovou notaci sekvencí čísla a pro slovníky pochopitelně zase neproměnné typy.

Tím chci říct, že magická metoda __getitem__() je pochopitelně ochotná „sežrat“ cokoliv, jen záleží na konkrétním objektu, co tím „cokoliv“ zrovna může být a jaký to bude mít zrovna význam.

📝
