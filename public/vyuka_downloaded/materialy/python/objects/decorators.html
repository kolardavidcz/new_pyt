Dekorátory tříd

by Jiří Znamenáček

1

Úvod

Jelikož (nejen) se třídami je v Python'u možné dělat nejrůznější vylomeniny (viz první čtyři slajdy této přednášky), asi nepřekvapí, že je můžeme i dekorovat stejným způsobem jako funkce.

📝
Nebo se na to dá koukat i úplně opačně: Všechno v Python'u jsou vlastně objekty, a to dokonce i funkce, které jsou svým způsobem objekty, které je možno volat (tzn. že mají atribut __call__). Tudíž pak už asi není tak moc překvapivé, že i k „obyčejným“ objektům se můžeme chovat podobně.

Jelikož aplikace dekorátorů je posledním krokem vytvoření nové třídy (tedy vlastně typu), je jasné, že by se to s těmi vylomeninami nemělo moc přehánět – z dekorované třídy by pořád ještě měla zůstat původní třída, jen nějakým vhodným způsobem upravená.

2

Příklad – řazení objektů

Dekorátory tříd nejsou tak běžné jako dekorátory funkcí. Nicméně i tak dokonce už i standardní knihovna nějaké obsahuje. Klasickým příkladem budiž @functools.total_ordering(): 

from functools import total_ordering

@total_ordering
class Student:
    
    def __init__(self, jméno, známka, věk):
        self.jméno = jméno
        self.známka = známka
        self.věk = věk
    
    def __repr__(self):
        return repr((self.jméno, self.známka, self.věk))
    
    def __eq__(self, jiný_student):
        return self.věk == jiný_student.věk
    
    def __lt__(self, jiný_student):
        return self.věk < jiný_student.věk

Instance této třídy je již možno porovnávat všemi šesti porovnávacími metodami, přestože jsme nadefinovali jenom dvě – uvedený dekorátor z nich totiž zbývající čtyři odvodil a přidal je k objektu třídy jako jeho atributy.

📝
Nebo spíš: Naplnil atributy existující již na odpovídající metatřídě skutečnou funkčností pro danou aplikaci.
