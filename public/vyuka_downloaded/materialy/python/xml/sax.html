SAX

by Jiří Znamenáček

1

Výhody a nevýhody DOMu

DOM má jednu ohromnou nevýhodu a zároveň i výhodu – zpracovávaný dokument musí být celý načten do paměti (byť třeba poodkládané na disk). Jakákoliv část dokumentu totiž musí být při zpracování dostupná.

To na jedné straně umožňuje provozovat operace, které by jinak nešly (XPath-dotazy nad strukturou, XSLT-transformace, aplikace na struktuře závislých CSS-pravidel…), na druhé straně se však může vyznačovat až prohibitivními nároky na paměť.

2

Enter SAX

V případech, kdy nepotřebujeme přístup k celé struktuře dokumentu najednou (např. získání zapsaných údajů z XML nebo výměna přesně určených elementů/atributů za předem známé jiné), můžeme s výhodou použít paměťově méně náročný (a nejen díky tomu často i mnohem rychlejší) lineární přístup ke XML-dokumentu pomocí (skoro)standardu SAX (Simple API for XML).

3

Princip

Princip SAXu spočívá v tom, že SAX-parser načítá dokument po (malých) částech a signalizuje, pokud narazí na XML-významnou strukturu:

  • textové listy
  • elementy včetně jejich atributů
  • komentáře
  • procesní instrukce

Vy jako uživatel pak můžete SAX-parseru předepsat, co má při daných událostech vykonat.

4

Načítání XML v Python'u

V Pythonu v typických případech stačí vytvořit potomka třídy xml.sax.ContentHandler, kterého vybavíte metodami pro ošetření začátku a konce elementu a textového obsahu: 

class MyHandler(xml.sax.ContentHandler):

  def startElement(self, name, attrs):
...

  def endElement(self, name):
...

  def characters(self, data):
...
📝
Přitom nemusíte vždy implementovat všechny metody, stačí pouze ty, které se vám zrovna hodí. Zajímá-li vás tudíž například zrovna pouze hodnota nějakého atributu, stačí nadefinovat pouze metodu startElement().

Zatímco name a data jsou řetězce (název elementu a jeho textový obsah), objekt attrs představující atributy daného elementu se na oko tváří jako slovník, ale není to tak úplně pravda, viz seznam jeho vlastností:

[ '__contains__', '__doc__', '__getitem__', '__init__', '__len__', '__module__', '_attrs', 'copy', 'get', 'getLength', 'getNameByQName', 'getNames', 'getQNameByName', 'getQNames', 'getType', 'getValue', 'getValueByQName', 'has_key', 'items', 'keys', 'values' ]

Typický cyklus přes atributy a jejich hodnoty tak bude nejspíše v této podobě: 

    for key, item in attrs.items():
5

Ukázka

Konkrétní použití vámi napsaného SAX-handleru pak může vypadat například takto: 

import xml.sax


class MyHandler(xml.sax.ContentHandler):

  def startElement(self, name, attrs):
    print( 'START:', name )

  def endElement(self, name):
    print( 'END:', name )

  def characters(self, data):
    print( data )


filename = "soubor.xml"
handler = MyHandler()
xml.sax.parse( filename, handler )
📝
Uvedený kód uvodí na výpise každý počáteční element nápisem START, každý koncový END a texty uvnitř elementů jednoduše přetiskne.
6

Poznámky

  • Z principu věci je ale SAX zřejmě jednosměrný – pokud cestou zjistíte, že potřebujete nějakou předchozí informaci a nezapamatovali jste si ji, máte smůlu a musíte začít dokument parsovat znovu od začátku.
  • Navíc SAX nemá ani nejmenší tušení o kontextu – jestli chcete sledovat třeba úroveň aktuálního zanoření (v rámci stromečku elementů), musíte se o to postarat sami.

PS: Rozhraní SAX v Python'u podporuje i jmenné prostory nebo tvorbu výstupních XML-dokumentů.
