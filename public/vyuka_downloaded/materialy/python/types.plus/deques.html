Objekty „deque“ – oboustranné fronty

by Jiří Znamenáček

1

Úvod

Ačkoli klasickou datovou strukturu fronta můžeme v Python'u nasimulovat pomocí seznamu, není seznam na přidávání a odebírání prvku ze začátku vůbec optimalizován – operace xs.pop(0) a xs.insert(0, x) mají náročnost O(n).

Potřebujete-li pro uvedené operace náročnost O(1), je pro vás připravena datová struktura oboustranná fronta v podobě (pod)modulu collections.deque.

2

Vlastnosti

Kromě snadného přidávání a odebírání prvků z obou stran podporuje deque i několik dalších zajímavých vychytávek:

  • za prvé je to z mnoha ohledů pořád seznam (resp. sekvence), takže funguje docela dost klasických sekvenčních operací (ale s několika důležitými výjimkami!);
  • umí rotovat svůj obsah o vybraný počet prvků vybraným směrem – rotate(n);
  • umí omezit svoji velikost na zadanou konečnou délku – parametr maxlen.

Na druhou stranu – zatímco přístup k libovolnému prvku seznamu pomocí xs[i] je prakticky O(1) operace, u oboustranné fronty je to pravda jen na koncích a pro prvky uprostřed náročnost vzrůstá na O(n).

📝
Ostatně nepřekvapivě – oboustranné fronty bývají implementovány především jako obousměrné spojové seznamy, zatímco pole zase jako kontinuální úseky paměti s jasnými začátky jednotlivých prvků.

PS: Kromě toho jsou dequey thread-safe.

3

Oboustranná fronta jako sekvence

Z mnoha ohledů se oboustranná fronta tváří jako sekvence, jedinou velkou výjimkou je snad nemožnost tvorby výřezů (tj. použití notace [::]): 

>>> from collections import deque
                
>>> xd = deque([1,2,3,4,3,5])
>>> xd
        deque([1, 2, 3, 4, 5])
        
        # délka (počet prvků)
>>> len(xd)
        6
        
        # test na přítomnost prvků
>>> 1 in xd
        True
>>> 3 not in xd
        False
        
        # prvek na konkrétním místě
>>> xd[0]
        1
>>> xd[-2]
        3
        
        # počet výskytů konkrétního prvku
>>> xd.count(3)
        2
        
        # otočení prvků (seznamová operace)
>>> xd.reverse()
>>> xd
        deque([5, 3, 4, 3, 2, 1])
4

Oboustranná fronta jako sekvence – smyčka „for-in“

Naprosto nepřekvapivě se po prvcích oboustranné fronty dá procházet klasicky pythonovsky pomocí smyčky for-in, a to samozřejmě pro libovolné typy prvků ve všech třech základních podobách: 

>>> xd = deque([5,2,3,1,4])
        
>>> for x in xd:
...   print(x)
...
        5
        2
        3
        1
        4
        
>>> for i,x in enumerate(xd):
...   print(i,x)
...
        0 5
        1 2
        2 3
        3 1
        4 4
        
>>> for x in reversed(xd):
...   print(x)
...
        4
        1
        3
        2
        5

Poslední varianta – řazení prvků pomocí funkce sorted() – funguje také, avšak můžeme ji použít pouze tehdy, jsou-li jednotlivé prvky porovnatelné, tzn. stejného typu (což zde funguje, protože jsem do fronty dával pouze čísla): 

>>> for x in sorted(xd):
...   print(x)
...
        1
        2
        3
        4
        5
5

Oboustranná fronta jako sekvence III – odstraňování prvků

Jelikož funguje (nejen) sekvenční operace indexace [i], funguje i klasické odstraňování prvků pomocí del (byť samozřejmě omezené na jediný prvek): 

>>> xd = deque([1,2,3,4,5])
        
>>> del xd[2]
>>> xd
        deque([1, 2, 4, 5])

Stejně jako u seznamů můžete odstranit první výskyt určitého prvku zleva pomocí metody remove(PRVEK): 

>>> xd = deque([1,2,3,4,3,5])
        
>>> xd.remove(3)
>>> xd
        deque([1, 2, 4, 3, 5])
📝
Také stejně jako u seznamů dostanete ValueError, pokusíte-li se odstranit prvek, který tam není.

A ještě jednou stejně jako u seznamů můžete celou frontu smazat pomocí metody clear(): 

>>> xd = deque([1,2,3,4,5])
>>> xd
        deque([1, 2, 3, 4, 5])
        
>>> xd.clear()
>>> xd
        deque([])

Základní operace I – „append(left)“ a „pop(left)“

Prvotním cílem práce s oboustrannou frontou je však možnost libovolně (a snadno) pracovat s prvky na obou jejích koncích: 

>>> xd = deque([1,2,3,4,5])
        
        # přidání a odebrání prvku na začátku
>>> xd.appendleft('a')
>>> xd
        deque(['a', 1, 2, 3, 4, 5])
>>> xd.popleft()
        'a'
>>> xd
        deque([1, 2, 3, 4, 5])
        
        # přidání a odebrání prvku na konci
>>> xd.append('a')
>>> xd
        deque([1, 2, 3, 4, 5, 'a'])
>>> xd.pop()
        'a'
>>> xd
        deque([1, 2, 3, 4, 5])
7

Základní operace II – „extend(left)“

Prvků se dá přidat také více najednou pomocí jedné operace, a to z libovolného iterovatelného objektu (úplně stejně jako u seznamu). Možná trochu překvapivě, avšak zcela pochopitelně, se nyní oboustranné varianty liší v pořadí přidání prvků: 

>>> xd = deque([1,2,3])
>>> xd
        deque([1, 2, 3])
        
        # Přidání na konec je očekávané:
>>> xd.extend('abc')
>>> xd
        deque([1, 2, 3, 'a', 'b', 'c'])
        
        # Přidání na začátek je ale „opačné“, tedy postupně prvek po prvku:
>>> xd.extendleft('abc')
>>> xd
        deque(['c', 'b', 'a', 1, 2, 3, 'a', 'b', 'c'])
8

Rotace prvků

Velmi pěknou operací je rotace prvků oboustranné fronty pomocí metody rotate(n) o n prvků vybraným směrem: 

>>> xd = deque([1,2,3,'a','b','c'])
>>> xd
        deque([1, 2, 3, 'a', 'b', 'c'])
        
        # Pro kladné „n“ rotujeme vpravo:
>>> xd.rotate(2)
>>> xd
        deque(['b', 'c', 1, 2, 3, 'a'])
        
        # Pro záporné pak na opačnou stranu, tedy vlevo:
>>> xd.rotate(-1)
>>> xd
        deque(['c', 1, 2, 3, 'a', 'b'])
9

Omezení délky fronty

Oboustrannou frontu je také možné zavést s nepovinným druhým parametrem maxlen, který pro jinou hodnotu než výchozí None omezí maximální délku fronty na zadané číslo. Přitom přidání prvků nad uvedený počet způsobí postupné umazávání prvků z opačného konce fronty: 

        # Oboustranná fronta s omezením délky:
>>> xd = deque([1,2,3], 5)
>>> xd
        deque([1, 2, 3], maxlen=5)
        
        # Dokud se do délky vlezeme, nic se neděje:
>>> xd.append(4)
>>> xd
        deque([1, 2, 3, 4], maxlen=5)
>>> xd.append(5)
>>> xd
        deque([1, 2, 3, 4, 5], maxlen=5)
        
        # Jakmile ji však přesáhneme, začnou z opačného konce mizet prvky:
>>> xd.append(6)
>>> xd
        deque([2, 3, 4, 5, 6], maxlen=5)
>>> xd.appendleft(7)
>>> xd
        deque([7, 2, 3, 4, 5], maxlen=5)
📝
Stejně tak dobře můžete frontu samozřejmě zavést jako xd = deque([1,2,3], maxlen=5).

Pár příkladů

Implementace unixového příkazu tail s využitím toho, že otevřený soubor je v Python'u iterovatelná struktura (bez inveci zkopírováno z dokumentace): 

        from collections import deque
        
        def tail(filename, n=10):
            'Return the last n lines of a file'
            with open(filename) as f:
                return deque(f, n)
📝
Funguje to tak, že deque(f) načte celý soubor postupnou iterací řádky po řádce, ale díky omezení velikosti fronty si zapamatuje pouze příslušný počet posledních.
