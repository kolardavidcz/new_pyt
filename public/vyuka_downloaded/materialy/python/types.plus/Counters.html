Objekty „Counter“ aka multisety (či „bagy“)

by Jiří Znamenáček

1

Úvod

Třída collections.Counter slouží ke snadnému počítání výskytů hešovatelných objektů: 

>>> from collections import Counter
>>> Counter('abrakadabra')
        Counter({'a': 5, 'r': 2, 'b': 2, 'k': 1, 'd': 1})

Principielně jde o slovník, jehož hodnotami by měla být celá čísla. Tento požadavek není při zavedení vynucován, ale nebudete-li se ho držet, můžete se asi dočkat překvapivých výsledků.

2

Zavedení

Zcela v duchu pythoní filozofie můžete Counter zavést mnoha rozdílnými způsoby: 

        # prázdný Counter
>>> Counter()
        Counter()
        
        # z iterovatelného typu (zde řetězce)
>>> Counter('gallahad')
        Counter({'a': 3, 'l': 2, 'g': 1, 'h': 1, 'd': 1})
        
        # ze slovníku
>>> Counter({'red': 4, 'blue': 2})
        Counter({'red': 4, 'blue': 2})
        
        # z pojmenovaných argumentů
>>> Counter(cats=4, dogs=8)
        Counter({'dogs': 8, 'cats': 4})
📝
Upraveno podle dokumentace.
3

„elements()“

Metoda elements() vrací iterátor přes každý klíč Counteru, a to tolikrát, kolik činí jeho odpovídající hodnota: 

>>> xc = Counter('abrakadabra')
>>> xc
        Counter({'a': 5, 'r': 2, 'b': 2, 'k': 1, 'd': 1})
>>> list(xc.elements())
        ['k', 'a', 'a', 'a', 'a', 'a', 'd', 'r', 'r', 'b', 'b']
📝
Pořadí vrácených klíčů je pochopitelně „náhodně“ slovníkové. Pokud už nejste na nějaké novější verzi Python'u (3.7+ s jistotou), kde je pořadí nepřekvapivě podle vstupu: 
>>> xc
            Counter({'a': 5, 'b': 2, 'r': 2, 'k': 1, 'd': 1})
>>> list( xc.elements() )
            ['a', 'a', 'a', 'a', 'a', 'b', 'b', 'r', 'r', 'k', 'd']

Klíče s nulovým nebo záporným počtem jsou přitom ignorovány: 

>>> xc = Counter(a=4, b=2, c=0, d=-2)
>>> list(xc.elements())
        ['a', 'a', 'a', 'a', 'b', 'b']
📝
Zatímco vynechání klíče s nulovým počtem je jasné, ignorace klíčů se záporným počtem (byť není na první pohled jasné, co by se s nimi mělo dělat) je prostě nadefinované chování.
4

„most_common([n])“

Metoda most_common([n]) vrací uspořádaný seznam n dvojic klíčů a jim odpovídajících počtů Counteru s největším počtem (tedy hodnotou klíče): 

>>> xc = Counter('abrakadabra')
>>> xc.most_common(3)
        [('a', 5), ('r', 2), ('b', 2)]
>>> xc.most_common(2)
        [('a', 5), ('r', 2)]
📝
Pro klíče se stejným počtem je pochopitelně vrácené pořadí slovníkově „náhodné“ a výsledek tak nemusí být vždy to, co by člověk čekal (jak je ostatně vidět v příkladu).

Bez udání počtu je vrácen celý Counter: 

>>> xc = Counter('abrakadabra')
>>> xc.most_common()
        [('a', 5), ('r', 2), ('b', 2), ('k', 1), ('d', 1)]
5

Skládání počtů – metodami

Dvě metody slouží ke složení počtu prvků dvou Counterů, resp. Counteru a iterovatelného typu (který je možno použít pro jeho zavedení):

  • metoda substract(ITERABLE) příslušné počty odčítá: 
    >>> xc = Counter('abrakadabra')
>>> xc
                Counter({'a': 5, 'r': 2, 'b': 2, 'k': 1, 'd': 1})
>>> xc.subtract('ananas')
>>> xc
                Counter({'a': 2, 'b': 2, 'r': 2, 'd': 1, 'k': 1, 's': -1, 'n': -2})
  • metoda update(ITERABLE) příslušné počty sčítá: 
    >>> xc = Counter('abrakadabra')
>>> xc
                Counter({'a': 5, 'r': 2, 'b': 2, 'k': 1, 'd': 1})
>>> xc.update('ananas')
>>> xc
                Counter({'a': 8, 'b': 2, 'n': 2, 'r': 2, 'd': 1, 's': 1, 'k': 1})
📝
V podstatě se chovají trochu jako metoda slovníků dict().update(), která ovšem hodnoty u stejných klíčů nahrazuje těmi novými.
6

Skládání počtů – operátorově

Podobně jako u množin máme u Counterů k dispozici i několik operátorových operací. Jejich specifikem je, že ignorují klíče se zápornými a nulovými počty. Předvedeme si je na následujících dvou objektech: 

        c1 = Counter(a=2, b=1, c=0, d=-2)
        c2 = Counter(a=3, b=2, c=1, d=-1)
  • Zatímco na sčítání není s uvedenou poznámkou nic překvapivého.. 
    >>> c1 + c2
                Counter({'a': 5, 'b': 3, 'c': 1})
  • ..odčítání už vypadá na první pohled trošku záhadně: 
    >>> c1 - c2
                Counter()
>>> c2 - c1
                Counter({'c': 1, 'a': 1, 'd': 1, 'b': 1})
  • Celé to ovšem funguje díky podpoře unárních operací + a -: 
    >>> -c1
                Counter({'d': 2})
>>> +c1
                Counter({'a': 2, 'b': 1})
  • Operátorový průnik & vrací symbolicky min(c1[x], c2[x]): 
    >>> c1 & c2
                Counter({'a': 2, 'b': 1})
  • Operátorové sjednocení | vrací symbolicky max(c1[x], c2[x]): 
    >>> c1 | c2
                Counter({'a': 3, 'b': 2, 'c': 1})

Souvislost (a rozdíly) se slovníkem

Kromě uvedených vlastních metod a operací sdílejí Countery všechny ostatní metody se slovníky, byť občas se některé chovají trošku jinak (jak jsme ostatně už viděli na předchozím slajdu u metody update()):

  • metoda fromkeys() je sice na Counterech přítomna, není však implementována;
  • dotaz na neexistující prvek neskončí s výjimkou KeyError jako u slovníků, ale zcela logicky vrátí nulu: 
    >>> xc = Counter('abrakadabra')
>>> xc['a']
                5
>>> xc['c']
                0
  • kopie Counteru yd = xc.copy() není překvapivě mělká: 
    >>> xc = Counter('abrakadabra')
>>> xc
                Counter({'a': 5, 'r': 2, 'b': 2, 'k': 1, 'd': 1})
>>> yc = xc.copy()
>>> yc
                Counter({'a': 5, 'r': 2, 'b': 2, 'd': 1, 'k': 1})
>>> del xc['d']
>>> xc
                Counter({'a': 5, 'r': 2, 'b': 2, 'k': 1})
>>> yc
                Counter({'a': 5, 'r': 2, 'b': 2, 'd': 1, 'k': 1})
8

Klasické slovníkové metody (přehled)

Všechny ostatní metody a způsoby procházení po prvcích jsou pak už stejné jako u klasických slovníků. Především jde tedy o:

  • klasické vlastnosti mapovacích a sekvenčních typů – len(xc), key in xc, for-in cyklus;
  • přístup k prvkům pomocí pohledů přes klíče (xc, xc.keys()), hodnoty (xc.values()) a dvojce klíč-hodnota (xc.items());
  • dotazy na prvky – x = get(klíč, výchozí=None), x = setdefault(klíč, výchozí=None);
  • přidávání prvků – xc[KLÍČ]=HODNOTA;
  • odstraňování prvků – del xc[KLÍČ], x = xc.pop(klíč, výchozí=None), x = xc.popitem(), xc.clear().
9

Příklady

Několik typických operací (přímo podle dokumentace):

Součet všech počtů: 

>>> xc = Counter('abrakadabra')
>>> xc
        Counter({'a': 5, 'r': 2, 'b': 2, 'k': 1, 'd': 1})
>>> sum(xc.values())
        11
>>> len('abrakadabra')
        11

n nejmenších počtů: 

>>> xc = Counter('abrakadabra')
>>> xc
        Counter({'a': 5, 'r': 2, 'b': 2, 'k': 1, 'd': 1})
>>> xc.most_common()[:-4:-1]
        [('d', 1), ('k', 1), ('b', 2)]
>>> xc.most_common()[:-3:-1]
        [('d', 1), ('k', 1)]
📝
Předpis tedy zní: xc.most_common()[:-n-1:-1]

Odstranění klíčů s nulovým a záporným počtem: 

>>> xc = Counter(a=2, b=1, c=0, d=-2)
>>> xc
        Counter({'a': 2, 'b': 1, 'c': 0, 'd': -2})
>>> +xc
        Counter({'a': 2, 'b': 1})
