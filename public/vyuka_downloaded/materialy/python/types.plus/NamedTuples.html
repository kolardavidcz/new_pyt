Objekty „namedtuple“ – n-tice se jmény pro prvky

by Jiří Znamenáček

1

Úvod

Mezi n-ticemi, slovníky a třídami zeje velká mezera pro typy, které nějakým způsobem kombinují vlastnosti všech tří. Jedním z nich jsou n-tice se jmény pro své prvky (též asi také pojmenované n-tice):

  • z jedné strany se chovají jako n-tice, tzn. že jsou neproměnným sekvenčním typem;
  • z druhé strany se podobají slovníkům, protože k jejich prvkům se dá přistupovat nejen podle pořadí, ale i podle jména;
  • a ze třetí strany se chovají ještě více spíše jako třídy bez metod, jejichž atributy neměníme.
2

Příklad

Příklad je (nejen) v tomto případě asi výmluvnější: 

>>> from collections import namedtuple
>>> def bod(x, y, z):
...     bod = namedtuple('bod_3D', 'x y z r')
...     from math import sqrt
...     return bod(x, y, z, sqrt(x*x + y*y + z*z))
         
>>> b = bod(2, 1, 3)
>>> b
        bod_3D(x=2, y=1, z=3, r=3.7416573867739413)
>>> b.z
        3

Proměnná b je tedy objektem o čtyřech prvcích (přičemž čtvrtý je dopočítán z prvních tří během zavedení), k nimž je možno přistupovat podle jejich jména.

3

Jména prvků

Z předchozího příkladu je vidět, že:

K prvkům pojmenované n-tice se podle jména přistupuje stejně jako u atributů tříd přes tečkovou notaci, tzn. že jméno prvku musí být validní pythoní identifikátor s výjimkou těch, jejichž jméno začíná na podtržítko.

Omezení na jména bez podtržítka je založené na tom, že podtržítkovaná jména jsou typicky vyhrazena pro pracovní či skryté vlastnosti objektů, a právě proto všechny pomocné metody objektu namedtuple začínají na podtržítka.

📝
Dvě metody toto omezení nesplňují – count() a index(). Jsou to pochopitelně právě jediné dvě metody vlastní typu n-tice.

Z prakticky stejného důvodu musí být pochopitelně jednotlivá jména jedinečná (bez duplikátů).

4

Jména prvků – parametr „_fields“

Jména jednotlivých prvků je možno jak z konstruktoru pojmenované n-tice, tak přímo z konkrétní instance vytáhnout pomocí parametru _fields: 

>>> Bod = namedtuple('Bod3D', 'x y z')
>>> Bod._fields
        ('x', 'y', 'z')
        
>>> bod = Bod(x=1, y=2, z=3)
>>> bod
        Bod3D(x=1, y=2, z=3)
>>> bod._fields
        ('x', 'y', 'z')

Vrácený objekt je n-tice, což umožňuje se jmény dále snadno pracovat.

5

Zavedení I

Zavést novou pojmenovanou n-tici znamená určit jméno jejího typu a jména jejích prvků:

nt = collections.namedtuple('JménoTypu', 'jména jednotlivých prvků')

Přitom jména prvků lze zadat několika různými způsoby: 

        # řetězec jmen oddělených mezerami
>>> NT = namedtuple('Bod3D', 'x y z')
>>> NT._fields
        ('x', 'y', 'z')
        
        # řetězec jmen oddělených čárkou
>>> NT = namedtuple('Bod3D', 'x,y,z')
>>> NT._fields
        ('x', 'y', 'z')
>>> NT = namedtuple('Bod3D', 'x, y, z')
>>> NT._fields
        ('x', 'y', 'z')
        
        # ze sekvence řetězců
>>> NT = namedtuple('Bod3D', ['x', 'y', 'z'])
>>> NT._fields
        ('x', 'y', 'z')
>>> NT = namedtuple('Bod3D', ('x', 'y', 'z'))
>>> NT._fields
        ('x', 'y', 'z')
6

Přístup k prvkům

Přístup pomocí jmen je jeden z hlavních důvodů pro existenci pojemnovaných n-tic, ale celkově se k jednotlivým prvkům dá přistupovat mnoha způsoby: 

>>> NT = namedtuple('Bod3D', 'x y z')
>>> bod = NT(x=1, y=2, z=3)
>>> bod
        Bod3D(x=1, y=2, z=3)
        
        # jménem jako u tříd
>>> bod.x
        1
        
        # pořadím jako u n-tic
>>> bod[0]
        1
        
        # z řetězce pomocí funkce „getattr()“
>>> getattr(bod, 'x')
        1
>>> jméno = 'x'
>>> getattr(bod, jméno)
        1
📝
Pro srovnání – u slovníků je přístup xs[KLÍČ], kde KLÍČem může být libovolný hešovatelný typ.
7

Zavedení II

Konstruktor pojmenované n-tice může dostat ještě jeden (pojmenovaný) parametr – rename. Jeho výchozí nastavení je False a nijak se neprojevuje, ale při přepnutí na True způsobí, že nevyhovující jména prvků budou automaticky přejmenována:

  • a) nepovolená jména 
    >>> student = namedtuple('Student', 'name class age gender')
                Traceback (most recent call last):
                  File "<stdin>", line 1, in <module>
                  File "/usr/lib/python3.4/collections/__init__.py", line 341, in namedtuple
                    'keyword: %r' % name)
                ValueError: Type names and field names cannot be a keyword: 'class'
                
>>> student = namedtuple('Student', 'name class age gender', rename=True)
>>> student._fields
                ('name', '_1', 'age', 'gender')
  • b) duplikace jmen 
    >>> student = namedtuple('Student', 'name age gender age')
                Traceback (most recent call last):
                  File "<stdin>", line 1, in <module>
                  File "/usr/lib/python3.4/collections/__init__.py", line 348, in namedtuple
                    raise ValueError('Encountered duplicate field name: %r' % name)
                ValueError: Encountered duplicate field name: 'age'
                
>>> student = namedtuple('Student', 'name age gender age', rename=True)
>>> student._fields
                ('name', 'age', 'gender', '_3')

8

Přiřazení hodnot

Jak jsme viděli na předchozích slajdech, instance pojmenovaných n-tic se typicky vyrábí pomocí volání konstruktoru s pojmenovanými parametry, ale jde to i pozičně: 

>>> Bod = namedtuple('Bod3D', 'x y z')
        
        # a) pozičně
>>> bod = Bod(1, 2, 3)
>>> bod
        Bod3D(x=1, y=2, z=3)
        
        # a) přeze jména
>>> bod = Bod(x=1, y=2, z=3)
>>> bod
        Bod3D(x=1, y=2, z=3)

Díky tomu lze ovšem s výhodou použít i triky s rozbalováním vhodných struktur za pomoci operátorů * a **: 

>>> Bod = namedtuple('Bod3D', 'x y z')
        
        # a) pozičně
>>> hodnoty = [1, 2, 3]
>>> bod = Bod(*hodnoty)
>>> bod
        Bod3D(x=1, y=2, z=3)
        
        # a) přeze jména
>>> hodnoty = {'x': 1, 'y': 2, 'z': 3}
>>> bod = Bod(**hodnoty)
>>> bod
        Bod3D(x=1, y=2, z=3)
9

Přiřazení hodnot pomocí „_make()“

Na přiřazování podle pozice je k dispozici ještě metoda _make(ITERABLE), která je schopna zpracovat téměř libovolný vstupní iterovatelný objekt: 

>>> Bod = namedtuple('Bod3D', 'x y z')
        
>>> bod = Bod._make([1, 2, 3])
>>> bod
        Bod3D(x=1, y=2, z=3)

Čehož se s velkou výhodou používá například při načítání hodnot z CSV-souborů nebo databází: 

        EmployeeRecord = namedtuple('EmployeeRecord', 'name, age, title, department, paygrade')
        
        import csv
        for emp in map(EmployeeRecord._make, csv.reader(open("employees.csv", "rb"))):
            print(emp.name, emp.title)
        
        import sqlite3
        conn = sqlite3.connect('/companydata')
        cursor = conn.cursor()
        cursor.execute('SELECT name, age, title, department, paygrade FROM employees')
        for emp in map(EmployeeRecord._make, cursor.fetchall()):
            print(emp.name, emp.title)

10

„_replace()“ – záměna hodnot

Ačkoli se pojmenované n-tice na venek stále tváří jako skutečné n-tice, to znamená jako neproměnné objekty, pomocí metody _replace(kwargs) lze na základě původní pojmenované n-tice vyrobit pojmenovanou n-tici novou, jejíž některé prvky budou obsahovat hodnoty nové: 

>>> Bod = namedtuple('Bod3D', 'x y z')
>>> bod = Bod(1, 2, 3)
>>> bod
        Bod3D(x=1, y=2, z=3)
        
        # záměnou je vrácena nová pojmenovaná n-tice
>>> bod._replace(y=6)
        Bod3D(x=1, y=6, z=3)
        
        # původní objekt zůstal nezměněn
>>> bod
        Bod3D(x=1, y=2, z=3)

📝
Tudíž provedete-li přiřazení bod = bod._replace(y=6), ve výsledku nahradíte původní n-tici n-ticí novou: 
            # původní „bod“
>>> bod
            Bod3D(x=1, y=2, z=3)
>>> id(bod)
            140361685120808
            
            # nový „bod“
>>> bod = bod._replace(y=6)
>>> bod
            Bod3D(x=1, y=6, z=3)
>>> id(bod)
            140361685121608
11

Další příklady

Výpisu jmen prvků pomocí _fields jde použít k „subklásování“: 

>>> Bod2D = namedtuple('Bod2D', 'x y')
>>> Bod2D._fields
        ('x', 'y')
        
>>> Bod3D = namedtuple('Bod3D', Bod2D._fields + ('z',))
>>> Bod3D._fields
        ('x', 'y', 'z')

Pomocí _replace() zase můžete simulovat výchozí hodnoty: 

>>> Account = namedtuple('Account', 'owner balance transaction_count')
        
        # výchozí pojmenovaná n-tice s předpřipravenými hodnotami
>>> default_account = Account('<owner name>', 0.0, 0)
>>> default_account
        Account(owner='<owner name>', balance=0.0, transaction_count=0)
        
        # výroba nového objektu – část hodnot výchozí, část nová
>>> johns_account = default_account._replace(owner='John')
>>> johns_account
        Account(owner='John', balance=0.0, transaction_count=0)

A konečně můžete pojmenovanou n-tici natvrdo podědit a upravit její funkcionalitu: 

>>> class Point(namedtuple('Point', 'x y')):
...   __slots__ = ()
...   @property
...   def hypot(self):
...     return (self.x ** 2 + self.y ** 2) ** 0.5
...   def __str__(self):
...     return 'Point: x=%6.3f  y=%6.3f  hypot=%6.3f' % (self.x, self.y, self.hypot)
... 
>>> for p in Point(3, 4), Point(14, 5/7):
...   print(p)
... 
        Point: x= 3.000  y= 4.000  hypot= 5.000
        Point: x=14.000  y= 0.714  hypot=14.018
