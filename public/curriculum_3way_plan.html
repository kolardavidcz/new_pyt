🎯 Cílová skupina:

Computer Science university students with background in C/C++ and Java moving to professional Python software engineering.

💡 Pedagogická filozofie:

Prioritizes idiomatic Pythonic thinking early (EAFP, Duck Typing, Sequences, Dicts, Generators, Dunders) before scaling out to Data Science, Databases, and Systems C-FFI.

Semestrální Milníky & Fáze:
Phase 1: Language Mental Model & Data Structures (W0–W3)
Establishes dynamic object reference model, sequences, hashing, and exception handling.
🏆 Milestone 1 (W3): CLI Tokenizér & Frekvenční analyzátor textu
Phase 2: Functions, Iterators & OOP Metaprogramming (W4–W6)
First-class functions, closures, generators, decorators, and the Python Data Model.
🏆 Milestone 2 (W6): Samopopisný Maticový datový model s perzistencí
Phase 3: Scientific Computing, Persistence & Data Science (W7–W9)
Multi-dimensional arrays (NumPy), modern I/O (pathlib, SQLite), and tabular analysis (Pandas).
Phase 4: Software Quality & Systems Engineering (W10–W11)
Robust testing, timeit profiling, subprocess management, binary buffers, and C-extensions (Cython/ctypes).
🏆 Milestone 3 (W11): Akcelerovaný CLI filtr signálů a obrazů v Cythonu / C-FFI
